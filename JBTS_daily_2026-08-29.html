각 방식의 정의

  • 예방보전(PM, Preventive Maintenance): 고장이 발생하기 전에 일정 주기로 점검·정비·교체를 실시하여 고장을 미연에 방지하는 보전 방식.
  • 사후보전(CM, Corrective Maintenance): 설비가 고장·기능 정지한 후에 원인을 제거하고 수리·복구하는 보전 방식.
  • 예측보전(PdM, Predictive Maintenance): 설비 상태를 상시 모니터링·측정하여 열화 추세를 분석하고 고장 시점을 예측해 최적 시기에 정비하는 방식.
🔑 구분 키워드 — PM=주기·계획(3년마다, 매월 정기) / CM=고장 후(두절, 정지) / PdM=추세·감시(모니터링, 서서히 증가). 문장에 시간표현이 있으면 PM, 과거 고장이 있으면 CM, 측정 데이터의 변화 추세가 있으면 PdM.

DRedirect(Type 5) 더 적절한 경로(다른 게이트웨이)가 있음을 알려 라우팅 테이블 수정을 유도

ICMP 개요(서술용)
ICMP(Internet Control Message Protocol)는 IP 계층(네트워크 계층)에서 동작하며, IP가 제공하지 못하는 오류 보고와 제어 메시지 전달을 담당하는 프로토콜이다. IP 헤더의 프로토콜 번호 1을 사용하며, 신뢰성·흐름제어는 제공하지 않는다. 주요 활용: ping(도달성·지연 측정), traceroute/tracert(경로 추적), 라우터 장애 진단.

🔑 4대 메시지 암기: Echo Request/Reply(8/0) · Destination Unreachable(3) · Time Exceeded(11) · Redirect(5). "traceroute의 원리를 쓰시오" → TTL을 1씩 증가시키며 보내고, 각 라우터가 되돌려주는 Time Exceeded로 경로를 파악.
