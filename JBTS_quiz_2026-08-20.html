▶ 모범답안 확인
다음 10가지 중 임의의 5가지를 쓰면 정답.
  1. 공사계획 및 공정표 검토
  2. 시공상세도면 검토
  3. 설계도서의 현장 적합성 확인
  4. 설계도서 준수 여부 확인
  5. 시공 진척 상황 조사
  6. 사용자재의 규격 검토·검사
  7. 재해예방 및 안전관리 지도
  8. 설계변경에 관한 사항 검토
  9. 하도급 타당성 검토

C03 · 공사원가 계산 (중요도 ★5 · 계산형)

문제. 어느 정보통신공사의 원가가 다음과 같을 때, 총원가를 구하시오.
재료비 40,000,000원 / 노무비 30,000,000원 / 경비 10,000,000원
일반관리비율 6%, 이윤율 15% (계산과정 포함, 원 단위 절사)
▶ 모범답안 확인
  1. 순공사원가 = 재료비 + 노무비 + 경비 = 40,000,000 + 30,000,000 + 10,000,000 = 80,000,000원
  2. 일반관리비 = 순공사원가 × 6% = 80,000,000 × 0.06 = 4,800,000원
  3. 이윤 = (노무비 + 경비 + 일반관리비) × 15% = (30,000,000 + 10,000,000 + 4,800,000) × 0.15 = 44,800,000 × 0.15 = 6,720,000원
  4. 총원가 = 80,000,000 + 4,800,000 + 6,720,000 = 91,520,000원
함정 주의: 이윤 산정 시 재료비는 제외한다. (노무비+경비+일반관리비)에만 이윤율을 곱한다. 이걸 틀리면 전 문항 오답 처리.

④ 절연저항은 ( ⓔ )V DC로 측정하여 ( ⓕ )MΩ 이상이어야 한다.

C06 · 가용성 / RAS (중요도 ★5 · 계산형 + 서술형)

문제 (1). 어떤 통신장비가 1년간 5회 고장났으며, 총 정상동작시간은 8,000시간, 총 수리시간은 40시간이었다. MTBF, MTTR, 가용성(A)을 각각 구하시오.

문제 (2). RAS의 3요소를 영문 원어와 함께 쓰고 각각의 대표 지표를 쓰시오.
▶ 모범답안 확인
(1) 계산
  1. MTBF = 총 정상동작시간 / 고장횟수 = 8,000 / 5 = 1,600시간
  2. MTTR = 총 수리시간 / 고장횟수 = 40 / 5 = 8시간
  3. 가용성 A = MTBF / (MTBF + MTTR) × 100 = 1,600 / 1,608 × 100 ≒ 99.50%
(2) RAS 3요소
구분영문지표 / 내용
신뢰성ReliabilityMTBF — 고장 없이 동작하는 정도, 이중화로 향상
가용성AvailabilityA = MTBF/(MTBF+MTTR) — 실제 사용 가능한 비율
보수성ServiceabilityMTTR — 고장 시 복구 용이성, 모듈화·원격관리로 향상
핵심: MTBF는 클수록 좋고 MTTR은 작을수록 좋다. 분모에 MTBF+MTTR(=MTBF+MTTR = 평균 사이클 시간)이 온다는 점 주의. 백분율(%) 단위와 소수 둘째 자리까지 반드시 표기.
자동 실행 안내 — 이 세션은 예약 실행(비대화형)으로 사용자 답변을 받을 수 없어, 채점 없이 문제 + 모범답안 학습지 형태로 생성했습니다. 따라서 SRS 트래커의 정답/오답 기록은 변경하지 않았습니다 (4개 토픽은 여전히 복습 대상으로 남아 있음). 실제 채점과 간격 갱신을 원하시면 대화창에서 필답형 훈련 시작이라고 입력해 주세요 — 답변을 받아 채점하고 트래커를 갱신합니다.
