ⓒ8월 말 예정공정 62%, 실적공정 47%임을 확인하고 시공사에 만회대책 제출을 요구함

[오류 ① 마 — 일반관리비 기준 오류]
일반관리비는 재료비가 아니라 순공사원가에 요율을 곱한다.

일반관리비 = 순공사원가 × 6% = 60,000,000 × 0.06 = 3,600,000원 (시공사 오류값 1,200,000원 → 2,400,000원 과소계상)

[오류 ② 바 — 이윤 산출 기준 오류]
이윤은 (노무비 + 경비 + 일반관리비)에 이윤율을 곱한다. 재료비는 이윤 산출 기준에서 제외된다.

이윤 = (노무비 + 경비 + 일반관리비) × 15% = (30,000,000 + 10,000,000 + 3,600,000) × 0.15 = 43,600,000 × 0.15 = 6,540,000원 (시공사 오류값 9,000,000원 → 2,460,000원 과다계상)

[오류 ③ 사 — 총원가 구성 누락 + 부가세 미계상]
총원가 = 순공사원가 + 일반관리비 + 이윤인데 일반관리비가 빠져 있고, 도급금액에는 부가가치세 10%가 가산되어야 한다.

총원가 = 60,000,000 + 3,600,000 + 6,540,000 = 70,140,000원 부가가치세 = 70,140,000 × 10% = 7,014,000원 도급금액 = 70,140,000 + 7,014,000 = 77,154,000원

C04접지저항 저감대책 설계 계산형
[문제 3] 100회선을 초과하는 구내통신설비의 접지공사에서, 접지극 1본을 시공하여 접지저항 30Ω이 측정되었다. 아래 물음에 답하시오. (11점)
  1. 이 설비의 접지저항 기준값과, 100회선 이하인 경우의 예외 기준값을 각각 쓰시오. (2점)
  2. 동일 규격 접지극을 병렬로 추가할 때, 상호간섭이 없다고 가정하면 기준값을 만족하기 위해 필요한 최소 접지극 본수는? (2점)
  3. 실제로는 상호간섭으로 병렬 저감효율이 80%라고 할 때, 3본·4본 시공 시의 합성 접지저항을 각각 구하고 합격 여부를 판정하시오. (4점)
  4. 위 1)의 두 기준값에 각각 적용하는 접지선의 최소 굵기(연동선 직경)를 쓰시오. (2점)
  5. 접지공사 완료 후 실시하는 절연저항 시험의 인가전압과 판정 기준을 쓰시오. (1점)
답안 작성란
정답·해설 펼치기

1) 일반(100회선 초과): 10Ω 이하 / 예외(100회선 이하): 100Ω 이하

2) 상호간섭이 없으면 합성저항 Rn = R / n

30 / n ≤ 10 → n ≥ 3 ∴ 최소 3본

3) 저감효율 80% 적용 → Rn = R / (n × 0.8)

3본: 30 / (3 × 0.8) = 30 / 2.4 = 12.5Ω → 10Ω 초과, 불합격 4본: 30 / (4 × 0.8) = 30 / 3.2 = 9.375Ω ≈ 9.38Ω → 10Ω 이하, 합격 ∴ 실제 시공에서는 4본이 필요하다.

※ 병렬 본수를 늘려도 상호간섭(중첩효과) 때문에 이론값만큼 떨어지지 않는다. 따라서 접지극 간 이격거리를 충분히(통상 접지극 길이의 2배 이상) 확보하거나, 접지저항 저감제·심타공법·메시(망상)접지를 병용한다.

4) 10Ω 기준 → 직경 2.6mm 이상 연동선 / 100Ω 기준 → 직경 1.6mm 이상 연동선

5) DC 500V 절연저항계(메거)로 측정하여 10MΩ 이상이면 합격.

🔑 접지 수치 4종 세트 — 10Ω / 예외 100Ω(100회선 이하) / 접지선 2.6mm·1.6mm / 절연 500V DC → 10MΩ 이상
⚠️ 함정: 절연저항 측정전압을 250V, 판정을 5MΩ으로 쓰는 오답이 가장 많다. 병렬 접지 계산은 "이론 R/n → 효율 적용 R/(n·η)" 순서로 반드시 2단 계산.
C06목표 SLA 역산형
[문제 4] 어떤 통신설비의 MTBF가 500시간이고 현재 MTTR은 2시간이다. 발주자는 SLA로 연간 가용도 99.9% 이상을 요구하고 있다. (12점)
  1. 가용도(A)의 정의식을 쓰고, 현재 설비의 가용도를 소수점 넷째 자리까지(%) 구하시오. (3점)
  2. 현재 상태의 연간 다운타임(시간)을 구하시오. (1년 = 8,760시간) (2점)
  3. SLA 99.9%를 만족하려면 MTBF를 그대로 둔 채 MTTR을 몇 분 이하로 줄여야 하는지 구하시오. (3점)
  4. 목표 99.9%인 장비 2대가 직렬(2대 모두 정상이어야 서비스 가능)일 때와 병렬 이중화일 때의 시스템 가용도를 각각 구하시오. (3점)
  5. RAS의 3요소를 쓰고, 각 요소에 대응하는 지표를 쓰시오. (1점)
답안 작성란
정답·해설 펼치기

1)

A = MTBF / (MTBF + MTTR) × 100 = 500 / (500 + 2) × 100 = 500 / 502 × 100 = 99.6016%

2) 불가용률 = 1 − 0.996016 = 0.003984

연간 다운타임 = 8,760 × 0.003984 ≈ 34.90시간 (약 34시간 54분)

3) A ≥ 0.999 조건을 MTTR에 대해 정리

MTBF / (MTBF + MTTR) ≥ 0.999 500 ≥ 0.999 × (500 + MTTR) MTTR ≤ MTBF × (1 − A) / A = 500 × 0.001 / 0.999 = 0.5005시간 ≈ 30.03분 ∴ MTTR을 약 30분 이하로 단축해야 한다. (이때 연간 다운타임 = 8,760 × 0.001 = 8.76시간)

MTTR 단축 수단: 예비품(Spare) 상시 확보, 모듈화·핫스왑 구조, 원격감시(NMS) 도입, 장애 대응 매뉴얼·비상연락체계 정비.

4)

직렬: A = 0.999 × 0.999 = 0.998001 → 99.8001% (연간 다운타임 8,760 × 0.001999 ≈ 17.51시간 — 오히려 나빠짐) 병렬(이중화): A = 1 − (1 − 0.999)² = 1 − 0.000001 = 0.999999 → 99.9999% (연간 다운타임 8,760 × 0.000001 ≈ 0.00876h ≈ 31.5초)

5) R = Reliability(신뢰성) → MTBF / A = Availability(가용성) → A = MTBF/(MTBF+MTTR) / S = Serviceability(보수성) → MTTR

🔑 MTBF = 총 정상동작시간 ÷ 고장횟수, MTTR = 총 수리시간 ÷ 고장횟수
역산 공식 MTTR ≤ MTBF × (1−A) / A 는 SLA 문제의 핵심. (A로 나누는 것을 빠뜨리면 오답)
⚠️ 함정: 직렬은 가용도가 곱해져 낮아지고, 병렬은 불가용률이 곱해져 높아진다. 직렬에 1−(1−A)²을 쓰는 실수 주의.
