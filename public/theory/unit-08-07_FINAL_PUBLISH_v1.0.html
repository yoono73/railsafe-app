TTC와 CTC — 제어범위와 구성

TTC 정의·구성요소(표시반·제어용콘솔·데이터전송장치) / TTC 정보 흐름 / TTC vs CTC 제어범위 비교 / 시험 함정 패턴

§0 선행 용어

TTC (Total Traffic Control)
열차종합제어장치. 1개 역 내부의 신호·선로전환기·조명 등 모든 설비를 원격으로 집중 제어하는 시스템
→ 제어 범위: 역 내부 전체 설비
CTC (Centralized Traffic Control)
열차집중제어장치. 복수 역·광역 선구 전체의 열차운행을 중앙 사령실에서 원격 제어하는 시스템
→ 제어 범위: 선구 전체 (다수 역)
표시반 (Display Panel)
TTC 구성요소 중 하나. 역 내 신호·설비 상태를 한눈에 표시하는 패널
→ TTC 3대 구성요소 중 하나
제어용콘솔 (Control Console)
TTC 구성요소 중 하나. 운전사령원이 역내 설비를 원격으로 조작·제어하는 콘솔 장치
→ TTC 3대 구성요소 중 하나
데이터전송장치 (Data Transmission Unit)
TTC 구성요소 중 하나. 중앙 제어실과 현장 설비 간 제어 명령 및 상태 데이터를 전송하는 장치
→ TTC 3대 구성요소 중 하나
연동장치
신호기·선로전환기의 안전 조건을 검증하는 장치. TTC 구성요소가 아님
→ TRAP: 연동장치 = TTC 구성요소 아님 ★

§1 TTC 정의 — 열차종합제어장치

C-29-A TTC(열차종합제어장치) 정의 및 특징 ★★★

TTC (Total Traffic Control, 열차종합제어장치): 1개 역 내부의 신호기·선로전환기·조명 등 모든 설비를 중앙에서 원격으로 집중 제어하는 시스템이다. 역무원 없이 무인 운영이 가능하다.

항목내용
정식 명칭Total Traffic Control (열차종합제어장치)
제어 범위1개 역 내부 전체 설비 — 신호기·선로전환기·조명 등
구성요소표시반 / 제어용콘솔 / 데이터전송장치 ★★★
역무원 운용역무원 없이 원격 운영 가능 (무인역 적용)
주요 적용도시철도·지하철 무인역
연동장치 = TTC 구성요소 → ❌ / 연동장치는 안전 조건 검증 장치이며 TTC 구성요소가 아님
TTC 구성요소 3가지: 표시반 · 제어용콘솔 · 데이터전송장치 — "표제데"로 암기
이론 배경 (SOURCE: 6.html 개념 29) TTC는 1개 역 내 신호·선로전환기·조명 등 모든 설비를 원격 집중 제어하는 시스템이다. 표시반(Display Panel)은 역 내 상태 표시, 제어용콘솔은 원격 조작, 데이터전송장치는 명령·상태 데이터 전송을 담당한다. 연동장치는 TTC와 별도로 안전조건 검증을 담당하므로 TTC 구성요소에 해당하지 않는다.

§2 TTC 구성요소 상세

C-29-B TTC 3대 구성요소 — 표시반·제어용콘솔·데이터전송장치 ★★★
구성요소역할핵심 키워드
표시반 역 내 신호기·선로전환기·조명 등 설비 상태를 한눈에 표시. 운전사령원이 역 전체 상황을 파악하는 모니터링 패널 상태 표시 · 모니터링
제어용콘솔 운전사령원이 역내 설비를 원격으로 직접 조작·제어하는 입력 장치. 신호기 현시 변경, 선로전환기 전환 등을 수행 원격 조작 · 제어 입력
데이터전송장치 중앙 제어실과 현장 설비 간 제어 명령 및 상태 정보를 양방향으로 전송하는 통신 장치 명령·상태 데이터 전송
TTC 구성요소에 해당하지 않는 것 → 연동장치 (안전 검증 전담, TTC와 별도)
TTC는 제어만 담당 — 안전 최종 검증은 연동장치가 별도 수행
이론 배경 TTC의 3대 구성요소는 각각 역할이 구분된다. 표시반은 현장 상태를 사령원에게 시각화하고, 제어용콘솔은 사령원의 조작 명령을 입력받으며, 데이터전송장치는 명령과 상태를 현장 설비와 실시간 교환한다. 이 세 구성요소가 협력하여 역 내 무인 자동화 운영을 구현한다.

§3 TTC 정보 흐름

C-29-C TTC 정보 흐름 — 사령실에서 현장까지 ★★

TTC 시스템에서 정보는 중앙 제어실(사령원) → 데이터전송장치 → 현장 설비의 방향으로 흐르며, 현장 상태는 역방향으로 데이터전송장치 → 표시반으로 환류된다.

흐름 방향경로내용
제어 명령 (하향) 제어용콘솔 → 데이터전송장치 → 현장 설비 신호기 현시 변경, 선로전환기 전환, 조명 제어 등
상태 정보 (상향) 현장 설비 → 데이터전송장치 → 표시반 설비 동작 상태, 고장 여부, 위치 정보 등
TTC는 양방향 정보 흐름 — 명령(하향) + 상태(상향)
TTC의 제어 명령은 연동장치를 통해 안전 검증 후 현장 설비에 적용됨. 연동장치가 TTC 구성요소인 것은 아님

§4 TTC vs CTC 제어범위 비교

보충 3 TTC vs CTC — 제어범위와 목적 비교 [빈출] ★★★
구분 TTC (Total Traffic Control) CTC (Centralized Traffic Control)
의미 열차종합제어장치 — 역내 모든 설비를 원격 집중 제어 열차집중제어장치 — 광역 선구의 열차운행 중앙 제어
제어 범위 1개 역 내부 전체 설비 (신호·선로전환기·조명 등) 복수 역·선구 전체 신호기·선로전환기
역무원 유무 역무원 없이 원격 운영 가능 각 역 역무원 불필요 → 중앙 집중 운용
주요 적용 도시철도·지하철 (무인역) 일반철도 장거리 선구
구성요소 표시반 / 제어용콘솔 / 데이터전송장치 TCC·MSC·표시장치 / LCP (현장역 설치)
❌ "CTC = 1개 역 장치 제어" → CTC는 선구 전체 열차 집중 제어 (1개 역은 TTC)
❌ "TTC와 CTC는 같은 의미" → 제어 범위와 목적이 다름
암기법: TTC = Total(총체적) → 역 내 전체 / CTC = Centralized(집중) → 선구 전체 열차
이론 배경 (SOURCE: 6.html 보충 3) TTC(Total Traffic Control)는 1개 역 내 신호·선로전환기·조명 등 모든 설비를 원격 집중 제어하는 시스템이다. CTC(Centralized Traffic Control)는 복수 역·광역 선구 전체의 열차운행을 중앙에서 제어한다. 이름이 비슷해 혼동하기 쉬우나 제어 범위(역 내 vs 선구 전체)가 근본적으로 다르다.
SOURCE 예시 "역내 모든 설비를 원격으로 집중 제어하는 장치" → TTC (CTC 아님 — CTC는 광역 선구 제어)
☞ CTC(열차집중제어장치) 상세 → UNIT 08-02 참조

§5 시험 포인트 · 함정 패턴

시험 포인트 총정리
  • [구성요소 함정] TTC 구성요소 = 표시반·제어용콘솔·데이터전송장치 ← 연동장치 제외
  • [정의 혼동] TTC ≠ CTC — 제어 범위가 다름: TTC(역 내) vs CTC(선구 전체)
  • [기능 혼동] 정속도 제어 → TTC 기능 아님 → ATO(자동열차운전장치) 기능
  • [역할 혼동] TTC는 역 내 모든 설비 제어 → 차내 방송·승객 안내도 포함
  • [출발·정지] 차량 출발·정지 제어 → TTC 기능에 포함
함정 유형오답 선택지정답·이유
구성요소 함정 연동장치가 TTC 구성요소 연동장치는 TTC 구성요소 아님 — 안전 검증 전담 장치
정의 혼동 CTC = 1개 역 제어 CTC = 선구 전체 / TTC = 1개 역 내부
기능 혼동 TTC = 정속도 제어 가능 정속도 제어는 ATO 기능 — TTC 기능 아님 ★
명칭 혼동 TTC = Total Traffic Center TTC = Total Traffic Control

확인 문제

Q1
출처: 철도왕 교재 ch82
열차종합제어장치(TTC)의 특징으로 옳지 않은 것은?
  • ① 정속도 제어가 가능하다
  • ② 차량 출발 및 정지 제어가 가능하다
  • ③ 차내 방송 및 승객 안내 기능을 포함한다
  • ④ 각종 차량 정보를 종합적으로 모니터링할 수 있다
정답: ① — TTC(열차종합제어장치)는 출발·정지·방송 등 열차 운행 전반을 종합 관리하는 장치이다. 정속도 제어는 포함되지 않으며, 이는 ATO(자동열차운전장치)의 기능이다.
