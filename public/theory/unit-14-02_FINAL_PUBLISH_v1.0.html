CONCEPT 01 — 공기조화·냉난방 시스템 SOURCE 84-A
CONCEPT 01 공기조화·냉난방 시스템 — 냉동사이클 핵심 요약
구분 내용
냉동사이클 순서 압축 → 응축 → 팽창 → 증발
암기: 압응팽증
압축 (Compression) 냉매를 고압·고온 기체로 압축
응축 (Condensation) 고압 기체 → 액체로 변환, 외부로 열 방출
팽창 (Expansion) 팽창밸브에서 압력 저하 → 저온·저압 액체
증발 (Evaporation) 저압 액체 → 기체로 증발, 주위에서 열 흡수 → 냉각
💡 시험 포인트: "압축→응축→팽창→증발" 순서만 확인. 응축과 팽창 순서 혼동 주의.
📖 상세 내용 참조: unit-08-04 §7-1 냉동사이클·압응팽증 — 냉동사이클 인포그래픽 포함. 해당 UNIT에서 상세 이론(각 단계 물리량 변화, 기출 예시)을 학습할 것.

CONCEPT 03 — 관절대차 SOURCE 94-A-1
CONCEPT 03 관절대차 (Articulated Bogie) — 구조·특성·함정
항목 내용
정의 인접한 두 차량이 하나의 대차를 공유하는 차량 구조
곡선 통과 우수 — 차량 간 이행부가 유연하게 연결되어 곡선 추종 성능 향상
승차감 향상 — 차량 간 진동 전달이 완화됨
대차 수 중간 대차를 공유하므로 일반 대차보다 수가 줄어든다
중량 가볍지 않음 — 구조가 복잡하고 중량이 늘어남 ← 오답 함정
[관절대차 이미지 — images/관절대차.png]

관절대차 — 인접 두 차량이 하나의 대차를 공유하는 구조

⚠️ 핵심 함정: "두 차량이 각자 독립된 대차를 가진다" → 오답.
관절대차는 인접 두 차량이 대차 하나를 공유한다는 것이 핵심 정의.
⚠️ "관절대차는 무게가 가볍다" → 오답. 구조 복잡도 증가로 중량 증가.
💡 적용 사례: TGV·Talgo 등 고속열차, 저상 트램(LRV) 등에서 곡선 통과 성능이 중요한 차량에 채택. PART 13에 미수록, UNIT 14-02 신규 수록.
CONCEPT 04 — 바이모달 트램 SOURCE 94-A-2
CONCEPT 04 바이모달 트램 (Bi-modal Tram) — 도로·궤도 겸용 차량
📌 표기 정정: GATE4 SOURCE 94-A-2 원제는 "바이모달 트럭(Bi-modal Truck)"으로 기재. 현행 정식 명칭은 바이모달 트램(Bi-modal Tram)으로 정정 수록. railway-king DB(Q864)도 "바이모달트램"으로 표기됨.
항목 내용
주행 방식 고무바퀴로 일반 도로 주행 + 자기유도·광학 등으로 트램처럼 정밀 선로 추종
특징 레일 없이도 정해진 경로를 정밀 추종 — 도로·궤도 겸용 혼합형 도시 교통수단
DB 구분 Q864: LIM·모노레일·AGT와 함께 경량전철 방식으로 분류 (구분 포인트)
⚠️ 경량전철 방식 혼동 주의 (DB Q864):
"선형 유도전동기로 급구배·급곡선에 유리한 방식" → LIM (바이모달 트램이 아님)
바이모달 트램은 고무바퀴 도로 주행 + 정밀 선로 추종이 핵심.
