§ 0. 먼저 알고 가는 용어 — 이 단원을 이해하기 위한 선행 개념
① 선로전환기 (Switch / Point Machine)
분기기에서 열차의 진행 진로를 바꾸기 위해 포인트를 전환하는 장치.
즉, 열차가 직진할지 분기할지를 결정하는 기기.
→ 연결: 분기기(§1), 정위·반위(§4), 전기선로전환기 8단계(§6)
② 분기기 (Turnout)
한 선로에서 두 개 이상의 선로로 갈라지게 하는 궤도 설비 전체.
포인트부(선로전환기가 있는 부분) + 리드부 + 크로싱부로 구성됨.
→ 연결: §1 분기기 구조, VIS-032
③ 텅레일 (Tongue Rail / 첨단궤조)
분기기 포인트부에서 기본레일(스톡레일)에 밀착하거나 떨어지며 진로를 형성하는 가동 레일.
텅레일이 한쪽 기본레일에 밀착되면 그 방향으로 진로 개통.
→ 연결: 대향(뾰족한 끝쪽 진입=탈선), 배향(넓은 쪽 진입=할출) → §10
④ 정위 (Normal Position)
선로전환기가 평상시 기본 위치로 정해 놓은 위치.
열차가 없을 때 기본적으로 유지하는 방향.
→ 연결: §4 정위·반위, §5 정위 결정 우선순위
⑤ 반위 (Reverse Position)
선로전환기가 정위의 반대쪽 진로로 전환된 상태.
열차를 분기선으로 보낼 때 전환하는 위치.
→ 연결: §4 정위·반위 비교
⑥ 전환 검지 (Indication Check)
선로전환기가 명령된 끝 위치까지 실제로 전환되었는지 확인하는 기능.
전환 미완료 시 표시등 미점등 → 신호기 진행 현시 불가(Fail-safe).
→ 연결: 전기선로전환기 ⑧표시 단계(§6)
⑦ 쇄정 (Locking)
설정된 진로에서 선로전환기가 임의로 움직이지 못하도록 잠그는 기능.
열차 통과 중 선로전환기가 움직이면 탈선 위험 → 쇄정으로 방지.
→ 07-08: 접근쇄정·진로쇄정·자기쇄정 상세는 07-08에서 다룸
§ 1. 분기기(Turnout) 구조 — 3부분
C1분기기 3부분 구성

VIS-032 분기기 구성 구조도

📐 이미지 읽는 법
분기기는 열차 진행 방향 기준으로 ①→②→③ 순서로 배치됨.
포인트부에 선로전환기가 위치하며 텅레일이 좌·우로 전환되어 진로를 결정함.
구분구성 부품역할
① 포인트부 (Point)텅레일 + 기본레일(스톡레일)진로 결정 — 텅레일이 좌·우 밀착으로 방향 전환
② 리드부 (Lead)리드레일(유도레일)포인트부에서 크로싱부까지 유도
③ 크로싱부 (Crossing)크로싱 + 호륜레일(가드레일)두 레일이 X자 교차하는 부분 — 차륜 통과 틈새 발생
⚠️ 순서 함정: 포인트부 → 리드부 → 크로싱부 (포→리→크) — 역순 출제 빈출
이론 배경: 크로싱부는 두 레일이 교차하며 차륜 주행 틈새(노치)가 발생해 충격·소음이 큼. 호륜레일(가드레일)이 차륜이 틈새로 빠지지 않도록 유도. 고속철도의 가동크로싱부 선로전환기는 이 크로싱부를 가동식으로 만들어 틈새를 제거함(결선부 제거).
§ 2. 선로전환기 종류 — 구조별 5종 + VIS-044
C2구조별 5종

VIS-044 선로전환기 분류체계 트리

📐 이미지 읽는 법
트리 왼쪽: 구조별 5종 / 오른쪽: 동력별(전기·수동·스프링) / 아래: 전환수(단동·쌍동·삼동)
종류특징함정 포인트
보통 선로전환기텅레일 2개, 좌·우 2개 분기가장 일반적
탈선 선로전환기과주 시 의도적 탈선 — 안전측선에 사용안전측선 ≠ 피난측선
가동크로싱부 선로전환기노스레일+텅레일 동시 이동 / 결선부 제거 / 고속철도결선부 "생성" → ❌
삼지선로전환기텅레일 4개, 좌·중·우 3개 분기텅레일 수 = 4개
전기선로전환기전동기 이용 전환 → 8단계(§6)콘덴서기동형 유도전동기
⚠️ 가동크로싱부 = 결선부 제거 (생성이 아님!). 고속철도 전용. ★★★
기출 예시
Q. 가동크로싱부 선로전환기의 특징으로 맞는 것은?
정답: 결선부 제거
오답함정: 결선부 생성 — 크로싱을 가동식으로 만들어 틈새(결선부)를 제거하는 것이 핵심
§ 3. 전환수 — 단동·쌍동·삼동
C3전환수 분류
전환수 분류버튼 1회 조작으로 동시 전환하는 선로전환기 수
단동(單動)1대
쌍동(雙動)2대
삼동(三動)3대
이론 배경: 전환수는 운전취급자가 버튼 1번 눌렀을 때 동시 전환되는 선로전환기 개수를 뜻함. 연동된 복수의 분기기를 한 번에 전환해 진로 설정을 단순화하는 목적.
§ 4. 정위·반위 — 정의 및 비교
C4정위(Normal)·반위(Reverse) 비교
정위 (Normal Position)
선로전환기를 평상시 기본 위치로 정해 놓은 위치.
열차 미운행 시 자동으로 유지되는 방향.
반위 (Reverse Position)
선로전환기가 정위의 반대쪽 진로로 전환된 상태.
열차를 분기선으로 보낼 때 전환하는 위치.
이론 배경: 정위는 단순히 "평상시 기본 위치"를 의미하며, 어느 방향이 정위인지는 §5의 우선순위 결정법에 따라 정해짐. 본선·안전측선 분기 지점에서는 안전측선 방향이 정위가 됨.
⚠️ 정위 ≠ "가장 안전한 방향" (이런 표현은 SOURCE에 없음 — 오답 함정으로 주의)
§ 5. 정위 결정법 — 5개 우선순위
C5정위 결정 우선순위 (순위가 높을수록 먼저 적용)
우선순위분기 상황정위 방향
1본선·본선 또는 측선·측선 분기주요 방향
2단선 상하본선 분기열차가 진입하는 방향
3본선·측선 분기본선 방향
4본선(측선)·안전측선 분기안전측선 방향 ★
5탈선선로전환기탈선시키는 방향 ★
⚠️ 안전측선 우선순위 함정: "본선·측선"에서는 본선이 정위지만, "본선·안전측선"에서는 안전측선이 정위! ★★
기출 예시
Q. 본선과 안전측선이 분기되는 곳에서 선로전환기 정위는?
정답: 안전측선 방향
오답함정: 본선 방향 — "본선·측선"이면 본선이지만, 안전측선이 있는 경우 안전측선 우선
§ 6. 전기선로전환기 8단계 계통도 ★★★
C68단계 계통도 — VIS-045 FINAL

VIS-045 전기선로전환기 계통도 FINAL — 8단계 및 주요 부품 상세

📐 이미지 읽는 법
상단: 8단계 흐름도 / 하단 3박스: ③전동기·⑥전환쇄정장치·④마찰클러치(마찰연축기) 상세
★ 표시 단계 = 빈출 함정 (④마찰클러치 여름·겨울, ③전동기 종류)
전기선로전환기 8단계 흐름
① 제어버튼 → ② 제어계전기 → ③ 전동기 → ④ 마찰클러치(마찰연축기) →
⑤ 감속기어장치 → ⑥ 전환쇄정장치 → ⑦ 회로제어기 → ⑧ 표시(표시등)
단계부품역할
①제어버튼운전취급자가 누름 — 전환 명령 시작
②제어계전기전원 회로 연결·차단 (자기유지 계전기)
③전동기콘덴서기동형 유도전동기가 회전력 생성 ★ → §7 상세
④마찰클러치(마찰연축기)과부하 시 슬립 → 기계 보호 ★ → §8 상세
⑤감속기어장치고속 회전 → 저속 고토크 변환
⑥전환쇄정장치해정 → 전환 → 쇄정 3작용 ★
⑦회로제어기전환 완료 감지 → 전동기 전원 차단
⑧표시(표시등)쇄정 완료 확인 — 정위/반위 표시등 점등
⚠️ 단계 순서 함정: 마찰클러치는 전동기(③) 바로 다음 ④번. 감속기어(⑤)보다 먼저임.
⚠️ ⑥ 전환쇄정장치 3작용 순서: 해정 → 전환 → 쇄정 (순서 교체 함정 빈출)

극수단상 4극

Q. 전기선로전환기 전동기의 종류는?
정답: 콘덴서기동형 유도전동기
오답함정: 동기전동기 — 유도전동기 사용, 동기전동기는 오답
§ 8. 마찰클러치(마찰연축기) — 여름·겨울 조정 ★★★
C8마찰클러치(마찰연축기) 계절별 조정
계절조정이유
여름강하게 ★레일 열팽창 → 포인트 레일이 주레일에 더 세게 밀착 → 전환저항 증가 → 큰 힘 필요
겨울약하게 ★결빙으로 포인트 레일 동결 가능 → 순간 과부하 발생 시 슬립 → 전동기·기어 보호
이론 배경 (SOURCE: 6.html §14):
마찰클러치는 "일정 힘 이상이 걸리면 슬립(미끄러짐)하여 기계를 보호"하는 장치.
• 여름=강하게: 고온으로 레일 팽창 → 포인트 레일이 주레일에 더 세게 밀착 → 전환 시 저항 증가 → 클러치를 강하게 설정해야 충분한 힘이 전달되어 전환 가능
• 겨울=약하게: 결빙으로 포인트 레일이 얼어붙을 수 있음 → 무리하게 전환 시 갑자기 큰 저항 → 클러치를 약하게 설정하면 슬립하여 전동기·기어 파손 방지
기억법: "여름=힘껏 밀어야 전환됨(강)" / "겨울=얼었을 때 무리하면 부서짐(약)"
⚠️ 최빈출 함정: "여름=약하게, 겨울=강하게" → ❌ 완전 반대!
정답: 여름=강하게, 겨울=약하게 ★★★
기출 예시 ★ 틀린 것 유형 (sig_282)
Q. NS형 전기선로전환기의 마찰클러치에 대한 설명으로 틀린 것은?
① 강하게 조정하면 전동기 정지 시 충격이 크고 공전 시 슬립 전류가 크게 된다
② 마찰클러치의 조정은 여름에는 약하게, 겨울에는 강하게 한다
③ 전동기가 회전 또는 정지할 때 기어에 충격을 주지 않도록 흡수한다
④ 첨단에 이물질이 끼거나 쇄정간이 걸릴 때 전동기를 보호한다
정답: ② — 여름=강하게, 겨울=약하게가 맞음. ②는 반대로 서술하여 틀린 내용
오답함정: ③ "기어 충격 흡수" — 이것은 맞는 설명이므로 정답 아님

§ 10. 대향·배향 — 진입 방향별 위험
C10대향(對向)·배향(背向) 비교
구분진입 방향위험
대향(對向)텅레일 뾰족한 끝(첨단부)으로 진입
— 포인트부 → 크로싱부 방향		탈선 우려 ★
배향(背向)텅레일 넓은 쪽에서 진입
— 크로싱부 → 포인트부 방향		할출 우려 ★
⚠️ 최빈출 함정: 대향=할출 / 배향=탈선 → ❌
정답: 대향=탈선, 배향=할출 (레일 벌어짐) ★★★
이론 배경: 대향 진입은 선로전환기 개통이 불완전하면 텅레일이 차륜을 다른 방향으로 밀어 탈선 위험. 배향 진입은 크로싱 방향에서 포인트 방향으로 진입하므로 개통 불완전 시 레일이 벌어지는 할출 위험.
기출 예시
Q. 선로전환기 배향 통과 시 우려되는 위험은?
정답: 할출
오답함정: 탈선 — 탈선은 대향 통과 시 위험, 배향은 할출
