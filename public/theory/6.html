PART 1. 철도신호 기본 개념 ▲
01신호·전호·표지 구분
용어수단목적
신호형상·색·음열차 운행 조건을 기관사에게 지시. 현시 기구=신호기
전호(Sign)몸짓·기구·음향관계자 상호간 의지 전달 (출발·비상·입환전호)
표지표시물위치·방향·조건을 표시 (고정 정보)
⚠️ 함정 주의: 전호 = 기관사에게 지시 → ❌ / 전호 = 관계자 상호간
이론 배경: 신호는 기계설비(신호기)가 열차에 지시를 내리는 것, 전호는 직원 상호 간 의사 전달, 표지는 위치·조건을 고정 표시한다.
기출 예시
Q. 역무원이 기관사에게 출발 지시를 내리는 것은?
정답: 전호 (사람이 사람에게 전달 = 전호)
오답함정: 신호 — 신호는 기계설비가 열차에 내리는 지시
02철도신호의 목적

궁극적 목적: 열차의 안전운행 확보 ★

최우선 사항: 절대안전 ★

이론 배경: 철도신호의 궁극적 목적은 열차 충돌·탈선을 방지하여 안전운행을 확보하는 것이다. 모든 신호 설비는 이 목적을 위해 존재하며, 최우선 사항은 절대안전이다.
PART 2. 신호기 구조상·조작상 분류 ▲
03구조상 분류 3종
종류현시 방법특징
완목식 신호기주간=완목 위치·형태 / 야간=등색주야간 현시방법 다름 ★
색등식 신호기색등으로 현시주야간 동일. 단등형(미사용)/다등형
등열식 신호기2개 이상 백색등 배열유도·중계신호기에 사용
⚠️ 함정 주의: 완목식만 주야간 현시방법이 다름. 색등식·등열식은 주야간 동일
💡 "현시(現示)"란?
신호기가 기관사에게 지금 상태를 눈으로 보여주는 것입니다.
예) 빨간 등 → "정지", 초록 등 → "진행" — 이렇게 색이나 형태로 정보를 전달하는 행위가 '현시'.

• 완목식: 낮에는 막대기(완목)의 각도·형태로, 밤에는 색등으로 → 낮과 밤이 다름 (오래된 방식)
• 색등식: 낮밤 구분 없이 항상 적·황·녹 색등으로 → 주야간 동일, 현재 가장 많이 사용
• 등열식: 여러 개 흰색 등의 배열 패턴으로 표시 → 유도·중계신호기 전용
이론 배경: 완목식만 주간(완목 위치·형태)과 야간(등색)의 현시 방법이 다르다. 색등식·등열식은 주야간 동일. 등열식은 유도·중계신호기에 전용으로 사용된다.
기출 예시
Q. 주야간 현시 방법이 서로 다른 신호기는?
정답: 완목식 신호기
오답함정: 색등식 — 색등식은 주야간 동일하게 색등으로 현시
04조작상 분류 3종
종류작동 방식사용 구간
수동신호기신호취급자가 레버 조작비자동구간
자동신호기궤도회로로 자동 현시 / 취급자 조작 불가자동폐색구간 폐색신호기
반자동신호기자동현시 + 취급자 조작 가능자동폐색구간 장내·출발신호기
⚠️ 함정 주의: 폐색신호기 = 자동 / 장내·출발 = 반자동 (혼동 주의)
이론 배경: 자동신호기는 궤도회로가 자동 현시하며 취급자 조작 불가. 반자동신호기는 자동 현시가 기본이지만 취급자 조작도 가능. 폐색신호기=자동, 장내·출발=반자동.
기출 예시
Q. 자동폐색구간 폐색신호기의 조작상 분류는?
정답: 자동신호기
오답함정: 반자동신호기 — 반자동신호기는 장내·출발신호기에 해당
PART 3. 신호기 기능별 분류 (주·종속·임시) ▲
05주신호기 6종

신호기 기능별 분류 계층 트리

종류기능설치 위치
장내신호기정거장 구내 진입 가부 지시대향 100m / 배향 60m
출발신호기정거장 출발 가부 지시출발선 시점
폐색신호기폐색구간 진입 가부 지시폐색구간 시작점
엄호신호기평면교차분기·특수시설 통과 열차 진입 가부특수지점 앞
유도신호기장내신호기 정지 시에도 예외 진입 허용장내신호기에 부속
입환신호기입환차량 진입 가부입환 구역

★ 폐색신호기 정위: 복선=진행 / 단선=정지
이론 배경: 주신호기 6종 역할: 장내=역 진입, 출발=역 출발, 폐색=구간 경계, 엄호=특수지점 보호, 유도=예외 진입 허용(정위=소등), 입환=입환 작업.
기출 예시
Q. 장내신호기 정지 현시 중에도 예외적으로 진입을 허용하는 신호기는?
정답: 유도신호기
오답함정: 폐색신호기 — 폐색신호기는 구간 경계 신호기, 예외 진입 허용 기능 없음
06종속신호기 3종
종류기능특징
원방신호기장내신호기 현시 예고비자동구간 / 정위=주의
통과신호기기계식 장내신호기 하단에서 통과 여부 지시기계식에만 사용
중계신호기주신호기 현시상태 예고·중계등열식 사용
⚠️ 함정 주의: 중계신호기 = 종속신호기 (주신호기 아님), 임시신호기도 아님 ★★
이론 배경: 종속신호기는 주신호기에 종속되어 예고·중계 역할만 하며 열차를 독립적으로 제어하지 않는다. 중계신호기는 종속신호기이며 임시신호기와 혼동하지 않아야 한다.
기출 예시
Q. 중계신호기는 어느 분류에 속하는가?
정답: 종속신호기
오답함정: 임시신호기 — 임시신호기는 서행예고·서행·서행해제 3종
07임시신호기 3종 ★ 비해당 자주 출제

서행예고신호기 / 서행신호기 / 서행해제신호기

⚠️ 함정 주의: 중계신호기는 임시신호기가 아님 ★
★ 임시신호기 비해당 = 중계신호기 — 매 회 출제
이론 배경: 임시신호기는 공사·장애 등 임시 상황에서 서행 구간을 표시하는 3종(서행예고·서행·서행해제)으로만 구성. 중계신호기는 종속신호기이므로 임시신호기 비해당으로 매회 출제된다.
기출 예시
Q. 임시신호기에 해당하지 않는 것은?
정답: 중계신호기 (임시신호기 3종: 서행예고·서행·서행해제)
오답함정: 서행신호기 — 서행신호기는 임시신호기 3종 중 하나
08신호부속기 & 운영상 분류

진로표시기: 장내·출발·입환신호기에 부속

진로 수진로표시기 종류
3진로 이하등렬식
4진로 이상문자식
구분해당 신호기정지 현시 시
절대신호기장내·출발·엄호·유도·입환절대 정지
허용신호기자동폐색구간 폐색신호기일단정지 후 서행 가능
이론 배경: 진로표시기는 신호기에 부속, 3진로 이하=등렬식, 4진로 이상=문자식. 절대신호기는 정지 현시 시 절대 정지, 허용신호기(자동폐색 폐색신호기)는 일단정지 후 서행 가능.

정답: 허용신호기 (일단정지 후 서행 가능)
오답함정: 절대신호기 — 장내·출발·엄호·유도·입환신호기가 절대신호기
PART 4. 신호기 정위 & 확인거리 ▲
09신호기 정위 암기표 ★ 핵심

신호기 정위 상태 암기카드

신호기정위 상태비고
장내·출발·입환·엄호정지
유도신호기소등(무현시)정지 아님! ★
폐색신호기 (복선)진행
폐색신호기 (단선)정지
원방신호기주의진행 아님! ★
⚠️ 함정 주의: 유도신호기 정위 = '정지' → ❌ 소등(무현시)
⚠️ 함정 주의: 원방신호기 정위 = '정지' → ❌ 주의
이론 배경: 정위는 평상시 신호기의 기본 상태. 3가지 예외: 복선 폐색신호기=진행, 원방신호기=주의, 유도신호기=소등(무현시). 이 3가지 예외가 시험 핵심.

💡 마찰클러치 여름=강 / 겨울=약 — 왜 직관과 반대인가?
마찰클러치는 "일정 힘 이상 걸리면 미끄러지는(슬립) 보호장치"입니다.
"강하게" = 버티는 힘이 커서 더 큰 힘도 전달 / "약하게" = 작은 힘에도 슬립하여 기계 보호

• 여름(강하게): 고온으로 레일이 팽창 → 포인트 레일이 주레일에 더 세게 밀착 → 전환 시 저항(마찰)이 커짐 → 클러치를 강하게 설정해야 충분한 힘이 전달되어 전환 가능
• 겨울(약하게): 결빙으로 포인트 레일이 얼어붙을 수 있음 → 무리하게 전환 시 갑자기 큰 저항 발생 → 클러치를 약하게 설정하면 이 순간 슬립하여 전동기·기어 파손 방지

기억법: "여름=강=힘껏 밀어야 전환됨" / "겨울=약=얼어있을 때 무리하면 부서짐"
이론 배경: 전기선로전환기 8단계: 제어버튼→제어계전기→전동기→마찰연축기→감속기어→전환쇄정→회로제어기→표시. 마찰클러치는 여름에 강하게, 겨울에 약하게 — 직관과 반대.

💡 궤도회로 기본 원리 — 어떻게 열차를 감지하는가?
차축(車軸) = 열차 바퀴를 좌우로 연결하는 쇠막대. 왼쪽 바퀴와 오른쪽 바퀴를 이어주는 금속 축입니다.

레일 두 개를 전선처럼 활용합니다:
• 정상(열차 없음): 한쪽 레일에 전류 보냄 → 레일 끝 계전기 → 반대쪽 레일로 복귀 → 계전기 여자(ON) = "구간 비어있음"

• Fail-safe: 레일 단선 고장도 계전기 낙하 → "열차 있음"으로 처리 → 안전 방향

한마디로: 계전기 ON = 안전, 계전기 OFF = 위험(열차 있음 또는 고장)

💡 임피던스 본드 — 귀선전류와 신호전류를 왜 분리해야 하나?

귀선전류(歸線電流) = 전차선에서 전동차로 공급된 전력이 모터를 돌린 후 레일을 통해 변전소로 돌아오는 전류. 수백~수천 암페어(A)의 대전류.
신호전류 = 궤도회로 감지용 전류. 수십~수백 밀리암페어(mA)의 미약한 전류.

문제: 두 전류가 같은 레일을 흐르면 → 수천 A 귀선전류가 수십 mA 신호전류를 덮어버림 → 계전기가 정상/열차있음 구분 불가

임피던스 본드의 해결 방식:
• 구조: 레일 중간에 설치된 코일(인덕터). 직류(DC)=저항 작음, 교류(AC)=저항 큼
• 귀선전류(직류 또는 저주파): 임피던스 본드 코일을 쉽게 통과 → 변전소로 복귀 ✅
• 신호전류(교류 고주파): 임피던스 본드에서 큰 저항(임피던스)을 만남 → 차단 → 신호 구간 내에 머뭄 ✅
→ 두 전류가 같은 레일을 흐르면서도 서로 간섭하지 않게 분리됨

💡 한류장치 — 차축 단락 시 왜 과전류가 발생하는가?
• 정상 상태: 궤도회로 전류는 레일 → 계전기(저항 있음) → 복귀 경로를 거침
• 차축 단락 시: 차축이 좌우 레일을 연결 → 계전기(저항)를 우회하는 지름길 생성 → 전류가 저항 없이 급격히 증가(단락 = 저항 거의 0 = 전류 폭등)
• 한류장치(저항 또는 리액터): 이 과전류를 제한하여 계전기·전원장치 보호
이론 배경: 임피던스 본드는 귀선전류(전차전류) 통과, 신호전류 차단하여 두 전류를 분리. 한류장치는 차축 단락 시 과전류로부터 기기를 보호 — 두 가지 기능을 혼동하지 않아야 한다.

PART 9. 연동장치 ▲
23연동장치 3종류
💡 연동장치가 왜 필요한가?
열차가 역에 진입하려면 두 가지가 동시에 맞아야 합니다:
① 선로전환기가 올바른 방향으로 놓여 있을 것
② 신호기가 진행(청색/녹색) 현시를 할 것

연동 없다면: 취급자가 실수로 선로전환기 방향이 틀린 채로 진행 신호를 내면 → 열차 탈선
연동 있다면: 선로전환기가 완전히 올바른 방향으로 쇄정(잠금)되기 전까지 → 신호기가 절대 진행을 현시 못함 → 자동 안전 보장

쉽게 말해: "포인트 잠금 확인 없이는 신호등 초록불 켜지지 않는 시스템"

신호기·선로전환기·궤도회로를 상호 연동하여 Fail-safe 실현

종류특징
기계연동장치레버 조작. 기기 간 연쇄 기계적 이루어짐. 궤도회로와는 연쇄 ❌
전기연동장치레버·버튼 집중. 계전기군에 의한 전기적 연쇄
전자연동장치계전기 로직을 전자 논리회로+컴퓨터+소프트웨어로 구성
⚠️ 함정 주의: 전자연동장치 구성요소: 표시제어부/광통신부/연동논리부 / LDTS ❌
이론 배경: 연동장치는 신호기가 진행을 현시하기 전에 선로전환기가 올바른 방향으로 쇄정되어야 한다는 Fail-safe 원칙을 실현. 기계연동장치는 궤도회로와 연쇄 불가.
기출 예시

정답: LDTS (구성요소: 표시제어부·광통신부·연동논리부)
오답함정: 연동논리부 — 연동논리부는 전자연동장치 핵심 구성요소
24진로 설정 방식
방식특징
진로정자식각 진로마다 1개 레버
단독정자식선로전환기 개별 전환 후 신호레버로 진로 구성
진로선별식출발점+도착점 버튼 2개 취급 → 자동 진로 선택 / 회로 간소화·접점 절약 ★
이론 배경: 진로선별식은 출발점·도착점 버튼 2개만 누르면 시스템이 자동으로 최적 진로를 선택. 취급이 간단하고 회로 접점이 절약되어 현대 연동장치에서 주로 사용된다.
기출 예시

정답: 진로선별식
오답함정: 진로정자식 — 진로정자식은 각 진로마다 1개 레버가 필요
25쇄정 종류 4가지 + 비해당
💡 쇄정 개념 먼저 — "갑"과 "을"이 연결된 두 선로전환기
역 구내에는 선로전환기(포인트)가 여러 개 있고, 서로 연동되어 있습니다.
갑(甲) = 첫 번째 선로전환기, 을(乙) = 두 번째 선로전환기
정위(正位) = 평상시 기본 방향(주로 직선), 반위(反位) = 바꾼 방향(분기)

쇄정이란: "갑이 특정 방향으로 전환되면, 을은 특정 위치에서 꼼짝도 못하게 잠근다"
→ 이유: 충돌 방지. 갑이 한 방향을 쓰고 있을 때 을이 멋대로 바뀌면 위험

★ 핵심 질문: "을이 어떤 위치로 잠기는가?"

① 정위쇄정: 갑 → 반위로 전환 시 → 을은 정위(기본방향)로 잠김
   예) 갑이 분기 방향으로 열차를 보내는 동안 → 을은 무조건 직선(정위) 고정

② 반위쇄정: 을이 이미 반위 상태일 때, 갑도 → 반위로 전환 시 → 을은 반위인 채로 잠김
   예) 을이 이미 분기 방향으로 바뀐 상태에서 → 갑까지 분기로 전환되면 → 을은 그 분기 위치(반위)에서 잠김

③ 정반위쇄정: 갑 → 반위로 전환 시 → 을은 정위든 반위든 현재 위치 그대로 잠김
   예) 갑이 반위로 가면 을은 지금 어떤 위치에 있든 그 자리에서 못 움직임
   → 정위쇄정+반위쇄정 두 경우를 동시에 포함 (가장 강한 쇄정)

④ 조건부쇄정: 다른 조건(버튼·신호 등)이 충족될 때만 잠금 적용

비해당 → 연속쇄정: 이런 종류 자체가 존재하지 않음 (시험에서 "해당 없음" 정답으로 출제)
종류잠기는 위치조건
정위쇄정을 → 정위로 잠김갑→반위 시
반위쇄정을 → 반위로 잠김을이 이미 반위 + 갑→반위 시
정반위쇄정을 → 현재 위치 그대로 잠김갑→반위 시 (정위·반위 무관)
조건부쇄정조건에 따라다른 버튼·조건 충족 시만
⚠️ 함정 주의: 연속쇄정 = 쇄정 종류에 없음 (비해당) ★
이론 배경: 쇄정은 잘못된 조작으로 선로전환기·신호기가 변환되지 않도록 잠그는 안전 장치. 공식 종류는 정위·반위·정반위·조건부쇄정 4가지. 연속쇄정은 존재하지 않는 비해당 항목.
기출 예시

💡 접근쇄정이란?
열차가 신호기 쪽으로 접근 중일 때, 안전을 위해 선로전환기를 자동으로 잠그는 것.
"이 열차가 오는 동안은 아무도 전환기 건드리지 마!" → 그게 접근쇄정.

그럼 왜 해정(잠금 해제)이 되냐?
① 열차가 통과 완료 → 궤도회로 개방 → 계전기 여자 → "이제 열차 없음" 확인 → 자동 해정
② 진로 취소됐는데 열차가 아직 가까이 있을 때 → 즉시 해정하면 위험! → 일정 시간(해정시분) 동안 잠금 유지 후 해정

해정시분이 필요한 이유: 진로 취소 직후 선로전환기를 즉시 바꾸면, 접근 중인 열차가 갑자기 바뀐 분기에 진입 → 탈선 위험. 그래서 최소 90초(장내) 또는 30초(출발·입환)는 잠금을 유지하다가 해정함.

보류쇄정접근쇄정에 준함 → 장내 기준 90초
⚠️ 함정 주의: 장내 = 90초, 출발·입환 = 30초 — 숫자 교체 함정 빈출
이론 배경: 접근쇄정 해정시분은 열차 접근 후 진로 취소 시 선로전환기를 잠그는 최소 시간. 장내 90초±10%, 출발·입환 30초±10%. 두 숫자를 교체하는 함정이 빈출.

43가점유·분로불량·레일절손 ★★ 신유형
현상원인결과
가점유 (Shunt Failure)차축 분로저항 과대 (도상절연불량·레일 녹 등)열차가 있어도 궤도회로 무점유(Free)로 표시 → 위험
분로불량차축과 레일 접촉 불량, 레일면 산화궤도계전기 낙하 불량 → 안전사고 위험
레일절손 검지궤도회로 전류 단절즉시 열차 있음(점유)으로 처리 (Fail-safe)
⚠️ 함정 주의: 가점유 = 열차가 없는데 점유 표시 → ❌ / 가점유는 열차가 있는데 무점유로 표시 (더 위험)
이론 배경: 가점유는 분로저항이 지나치게 커서 차축 단락 효과가 미미해 열차를 감지 못 함. 레일절손은 궤도회로 개방이므로 Fail-safe에 따라 점유 처리.
기출 예시

오답함정: 레일절손 — 레일절손은 궤도회로 단선으로 점유 표시됨 (가점유와 반대)
