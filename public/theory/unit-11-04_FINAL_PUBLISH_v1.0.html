§0 선행 용어
VVVF (Variable Voltage Variable Frequency)
가변전압가변주파수. 인버터로 전압과 주파수를 동시에 가변하여 유도전동기 회전속도를 제어하는 방식.
컨버터 (Converter)
교류(AC) → 직류(DC) 변환 장치. 주회로에서 팬터그래프로부터 받은 교류 전력을 정류하여 직류 링크 전압 생성.
인버터 (Inverter)
직류(DC) → 교류(AC) 변환 장치. VVVF 인버터는 전압·주파수를 가변하여 3상 교류로 출력 → 유도전동기 구동.
주회로 (Main Circuit)
집전장치에서 전동기까지 전력이 흐르는 주 전력 경로. 팬터그래프→변압기→컨버터→인버터→전동기.
회생제동 (Regenerative Braking)
제동 시 전동기를 발전기로 전환하여 운동에너지를 전기에너지로 회수. 발생 전력을 가선으로 반환.
직류 링크 (DC Link)
컨버터와 인버터 사이의 직류 구간. 평활 콘덴서로 직류 전압 안정화.
§1 VVVF 추진제어 원리 (SOURCE13·SOURCE53·SOURCE59)
4.html 개념13·53·59 VVVF 인버터 제어 — 원리 및 특징 ★★★
항목내용
VVVF 원리인버터가 전압(V)과 주파수(F)를 동시에 가변 → 3상 유도전동기 속도 무단 제어
속도 증가 시전압↑ + 주파수↑ → 회전자계 빠르게 → 전동기 가속
속도 감소 시전압↓ + 주파수↓ → 회전자계 느리게 → 전동기 감속
회생제동인버터 역동작 → 전동기 발전기 전환 → 직류 링크 → 컨버터 역방향 → 가선 반환
장점광범위 속도제어, 에너지 회생, 유지보수 용이 (구조 간단한 유도전동기 사용)
전동기 용량과의 관계열차 중량·구배·가속도·운전속도·주행저항(5대 결정요인)에 맞게 VVVF가 출력을 정밀 제어 (4.html 개념53)
🎯 핵심: V(전압)와 F(주파수)를 비례하여 제어 (V/F 비 일정 유지) → 자속 일정 → 효율적 제어
§2 주회로 구성 (SOURCE59·F-10)
4.html 개념59 · F-10 전동차 주회로 — 전력 흐름 ★★★
교류 전동차 주회로 흐름:
가선(AC) → 팬터그래프(집전) → 주변압기(전압 강하) → 컨버터(AC→DC) → 직류 링크 (평활 콘덴서) → 인버터(DC→AC 3상, VVVF) → 유도전동기(구동)
구성 요소역할변환
팬터그래프가선에서 전력 집전AC 25kV(고속선) 또는 AC 25kV/1.5kV
주변압기전압 강하, 절연고전압 AC → 저전압 AC
컨버터AC → DC 변환, 전력인수AC → DC 직류 링크
직류 링크전압 평활화DC 전압 안정 유지
인버터(VVVF)DC → AC 변환, 전압·주파수 가변DC → 3상 AC (가변)
견인전동기전기→회전력3상 AC 입력 → 토크 출력
⚠️ 컨버터와 인버터 역할 혼동 주의:
컨버터 = AC→DC (집전 측) | 인버터 = DC→AC (전동기 측)
회생제동 시 인버터가 역방향으로 동작하여 발전기에서 나온 AC를 DC로 → 컨버터가 DC→AC로 가선 반환
§3 LIM 추진제어 — VVVF 연계 (SOURCE84-B)
4.html 개념84-B LIM 추진제어 — VVVF 인버터 연계 ★★
항목내용
LIM 제어 방식VVVF 인버터로 1차 코일에 인가하는 전압·주파수 가변 → 이동자계 속도 조절 → 추진력 제어
회전형 IM과 차이출력: 회전토크 대신 직선 추진력(N) / 기어 불필요
제어 원리주파수↑ → 이동자계 속도↑ → 추진력↑ (회전형과 동일 제어 원리)
📌 LIM 전동기적 원리(직선 전개, 이동자계, 반작용판) → 11-03에서 다룸
§4 시험 포인트 · 함정
🎯 핵심 암기 포인트
  • VVVF = 전압(V)과 주파수(F) 동시 가변 → 유도전동기 속도 제어
  • 컨버터 = AC→DC / 인버터 = DC→AC (혼동 금지)
  • 주회로: 팬터그래프→변압기→컨버터→직류링크→인버터→전동기
  • 회생제동 = 전동기→발전기 전환 → 가선 반환
  • LIM도 VVVF 인버터로 추진력(직선) 제어
함정 선택지정오근거
"인버터는 DC를 AC로 변환한다" ✅ 정답 인버터 = DC→AC (정의 자체가 맞음)
"컨버터는 DC를 AC로 변환한다" ❌ 오답 컨버터 = AC→DC (역방향 혼동)
"VVVF는 전압만 가변한다" ❌ 오답 전압·주파수 동시 가변
"LIM은 회전형과 달리 VVVF 제어 불가" ❌ 오답 LIM도 VVVF 인버터로 추진력 제어

Q1 engineering id:16 · SOURCE: 4.html 개념13 · VVVF 유도전동기
현대 전동차에서 주로 사용하는 추진전동기와 제어 방식의 조합으로 옳은 것은?
  1. ① 직류직권전동기 — VVVF 인버터 제어
  2. ② 직류직권전동기 — 저항 제어
  3. ③ 3상 유도전동기 — VVVF 인버터 제어
  4. ④ 3상 유도전동기 — 저항 제어
정답: ③ 3상 유도전동기 — VVVF 인버터 제어
현대 전동차는 3상 유도전동기를 VVVF(가변전압가변주파수) 인버터로 제어하는 것이 표준이다. 직류직권전동기는 저항·약계자·전압 제어를 사용하는 구형 방식이다.
Q2 engineering id:16 · SOURCE: 4.html 개념59 · 주회로
전동차 주회로에서 교류를 직류로 변환하는 장치는?
  1. ① 인버터(Inverter)
  2. ② 컨버터(Converter)
  3. ③ 변압기(Transformer)
  4. ④ 인터록(Interlock)
정답: ② 컨버터(Converter)
컨버터는 AC→DC 변환 장치다. 인버터는 DC→AC 변환(반대 방향)이므로 혼동 주의.
Q3 rk_756 · SOURCE: 4.html 개념84-B · LIM 추진제어
LIM(선형유도전동기)의 추진력을 제어하는 방법으로 옳은 것은?
  1. ① 저항값을 변화시켜 전류를 조절한다.
  2. ② VVVF 인버터로 전압·주파수를 가변하여 이동자계 속도를 조절한다.
  3. ③ 기어비를 조절하여 추진력을 변화시킨다.
  4. ④ 약계자 제어로 속도를 가변한다.
정답: ② VVVF 인버터로 전압·주파수를 가변
LIM도 VVVF 인버터로 1차 코일의 전압·주파수를 조절하여 이동자계 속도를 제어한다. LIM은 기어가 없으므로 기어비 조절(③)은 불가하다.
