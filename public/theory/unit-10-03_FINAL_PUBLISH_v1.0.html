§0 선행 용어
전차선 (Contact Wire)
팬터그래프가 직접 슬라이딩 접촉하는 하부 전선. 구비조건을 만족해야 안전·고효율 집전 가능.
구비조건 (Requirements)
전차선이 갖추어야 할 전기적·기계적 성질의 최소 요건. 전도도·강도·유지보수성·내마모성이 핵심.
편위 (Stagger / Offset)
전차선이 선로 중심선에서 가로 방향으로 치우친 거리. 팬터그래프 편마모 방지 목적으로 설정.
절연구간 (Neutral Section)
인접 급전구역 사이에서 전기적으로 분리된 구간. 팬터그래프가 통과할 때 이격·편위 기준 준수 필수.
§1 전차선 구비조건 (개념80-B)

순서구비조건의미
① 전기전도도가 높을 것 전류 전달 손실 최소화 — 집전 효율 확보
② 기계적 강도가 클 것 팬터그래프 충격·장력에 견딜 것
③ 유지보수가 용이할 것 점검·교체 작업이 쉬울 것
④ 내마모성이 좋을 것 팬터그래프와 반복 마찰에도 수명 유지
⚠️ 함정 — 가선금구류 중량화
"가선금구류를 중량화할 것" → 전차선 구비조건이 아님
금구류 중량화는 전차선 요건 아니라 지지물 구조 문제

§3 시험 포인트
🎯 수치 혼동 주의 — 300mm vs 250mm
  • 절연 이격거리 = 300mm 이상 (10-02 참조)
  • 전차선 편위 = 250mm
  • 시험에서 "편위는 300mm이다" → ❌ 오답, 편위는 250mm
  • 시험에서 "이격거리는 250mm이다" → ❌ 오답, 이격거리는 300mm
🎯 전차선 구비조건 함정
  • 구비조건 4종: 전기전도도·기계적 강도·유지보수 용이·내마모성
  • "가선금구류 중량화" → 구비조건 아님 — 함정 선지로 자주 등장
함정 선택지정오근거
"전차선 편위 = 300mm" ❌ 오답 편위 = 250mm, 300mm는 이격거리
"가선금구류 중량화" 구비조건 ❌ 오답 구비조건 4종에 포함되지 않음
"내식성이 높을 것" 구비조건 △ 주의 SOURCE 미확인 — 내마모성과 혼동 금지
