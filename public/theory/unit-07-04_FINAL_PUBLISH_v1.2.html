§ 0. 먼저 알고 가는 용어 — 이 단원을 이해하기 위한 선행 개념
① 건널목 (Level Crossing)
도로와 철도 선로가 같은 평면에서 교차하는 장소. 차량·보행자와 열차가 동일 평면을 공유하므로 경보·차단 설비가 필수.
→ 연결: §1 건널목 3종 분류, §2 경보장치 수치
② 전동차단기 (Electric Barrier)
전동기의 구동력으로 차단봉을 하강·상승시켜 건널목 차량 통행을 차단하는 장치.
→ 연결: §2 경보장치 수치(하강·상승 시간), §3 전동차단기 구성
③ 직류직권전동기 (DC Series Motor)
직류 전원을 사용하며 계자 권선과 전기자 권선이 직렬 연결된 전동기. 전동차단기의 구동에 사용. 기동 토크가 크고 속도 제어가 용이한 특성이 있다.
주의: 전기선로전환기(07-03)는 콘덴서기동형 유도전동기(단상 4극)를 사용하므로 혼동 금지.
→ 연결: §3 전동차단기 구성, 07-03 선로전환기
④ 마찰연축기·감속치차 (Friction Clutch · Reduction Gear)
마찰연축기(마찰클러치): 전동기 동력을 차단봉 구동축에 연결·분리하는 안전장치. 과부하 시 슬립하여 기계적 손상을 방지.
감속치차(감속기어): 전동기의 고속 회전을 낮은 속도·높은 토크로 변환하여 차단봉을 안정적으로 작동시킴.
→ 연결: §3 전동차단기 구성
⑤ 궤도회로 / 궤도단락 (Track Circuit / Track Shunting)
궤도회로: 레일을 전기회로의 일부로 사용하여 열차 유무를 검지하는 장치. 건널목에서 열차 접근 감지의 기본 원리.
궤도단락: 열차의 금속 차축이 양쪽 레일을 단락(단전)시켜 열차 검지 신호가 발생하는 현상.
→ 연결: §5 검지장치 종류, 07-06 기본 궤도회로
⑥ 호륜레일 (Guard Rail)
건널목 내 포장 면과 레일 사이에 설치하는 보조 레일. 차량 바퀴가 레일 안쪽으로 빠지는 것을 방지하고 열차 주행 안전을 확보. 건널목 안전설비의 구조적 요소.
→ 연결: §1 건널목 3종 분류

§2. 경보장치 수치 — 암기 필수 ★★★
개념04경보장치 7가지 수치
📌 그림 보는 법
① 경보등과 경보종의 횟수를 먼저 구분한다.

§3. 전동차단기 구성
개념05전동차단기 3대 구성요소
전동차단기 3대 구성요소
① 마찰연축기 (마찰 클러치) — 과부하 시 미끄러져 차단봉 보호
② 직류직권전동기 — 구동 전동기 (차단봉 승강 동력원)
③ 감속치차 — 전동기 속도를 감속하여 토크 증대
★ 전압검지장치는 전동차단기 구성요소가 아님! 오답 선택지로 자주 등장.
이론 배경: 마찰연축기의 역할 = 이상 하중(차량 충돌 등)이 가해질 때 슬립(미끄러짐)으로 차단봉 파손 방지.
📌 그림 보는 법
① 직류직권전동기
   → 차단봉을 움직이는 회전력을 만든다.
② 감속치차
   → 전동기의 빠른 회전을 감속하고 토크를 증가시킨다.
③ 마찰연축기(마찰클러치)
   → 이상 하중이 발생하면 미끄러져 차단봉과 구동장치를 보호한다.
④ 최종적으로 구동축을 통해 차단봉을 하강·상승시킨다.

★ 암기:
   전동기 = 힘을 만든다
   → 감속치차 = 속도를 낮추고 힘을 키운다
   → 마찰연축기 = 과부하에서 보호한다
   → 차단봉 = 승강

§6. 시험 함정 정리
1. "2종 건널목에도 차단기가 있어야 한다" → ✕ 2종=경보기+표지만, 차단기 없음
2. "역구내 건널목 = 수동 기본" → ✕ 자동이 기본
3. "차단기 하강 시간 = 12초 이하" → ✕ 하강=8±2초, 12초 이하는 상승 시간
4. "경보등 점멸 = 70~100회" → ✕ 경보등=40±10회 / 경보종이 70~100회
5. "전동차단기 구성요소 = 전압검지장치" → ✕ 마찰연축기·직류직권전동기·감속치차 3가지
6. "전동차단기 제어전압 허용 = ±10%" → ✕ 제어전압=0.9~1.2배 / ±10%는 코일 전류
7. "열차 편성량 = 건널목 보안설비 설치 고려 요소" → ✕ 고려 요소 아님
§7. 연결 단원
이 단원과 연결되는 핵심 개념
- 07-03 선로전환기: 전동차단기=직류직권전동기 / 전기선로전환기=콘덴서기동형 유도전동기(단상 4극) — 구동·감속·보호기구 구성은 유사하나 전동기 형식이 다르므로 혼동 금지
- §검지장치 9종: 끌림검지장치 등 — 건널목 지장물 검지도 포함
- 철도안전법: 건널목 사고 예방 조치 (1종=자동차단기 의무, 사고다발=입체화 추진)

Q01 [sig_274·S] 전동차단기 하강 시간
정답 ② 8초 ± 2초
전동차단기 하강 시간 = 8초 ± 2초 (6~10초 범위). 상승 시간 = 12초 이하.
③ 12초는 상승 시간. '20초 이내'는 규정에 없는 오답.
Q02 [sig_275·A+] 경보등 점멸 횟수
정답 ② 분당 40 ± 10회
직립형 경보등 점멸 = 분당 40 ± 10회 (30~50회). 경보종 타종수와 혼동 금지.
④ 70~100회는 경보종(벨) 타종 횟수.
Q03 [sig_276·A+] 경보종 타종 횟수
정답 ③ 분당 70 ~ 100회
경보종 타종수 = 분당 70~100회. 경보등 점멸(40±10회)과 구분.
① 40±10회는 경보등. ② 60~90회는 오답 수치.
Q04 [sig_277·A+] 전동차단기 제어전압
정답 ② 정격값의 0.9 ~ 1.2배
전동차단기 제어전압 = 정격값의 0.9~1.2배. 코일 전류 = ±10%.
③ ±10%는 경보종 코일 전류 허용 편차. 제어전압과 혼동 금지.
Q05 [eng_72·A] 가장 안전한 건널목
정답 ① 제1종 건널목
제1종 = 차단기+경보기 필수(가장 안전). 관리원은 「철도시설의 기술기준」 별표 기준에 따라 배치. 제2종 = 경보기만. 제3종 = 안전표지만.
원문 문제의 "신호기" 표현은 교재 원문 표현. 현행 기준상 제1종 핵심 설비는 차단기+경보기이며 관리원을 필수 구성 요건으로 혼동하지 말 것. 1종>2종>3종 안전 순.
Q06 [rk_ch81_16] 건널목 정의 틀린 것
정답 ④ 제2종 건널목에는 반드시 차단기와 안내원이 있어야 한다
제2종 = 경보기+안전표지만. 차단기·안내원 없음. ①③는 옳음.
제2종을 1종처럼 설명한 선택지 → 오답.
※ 문제의 '안내원'은 SOURCE 원문 표현이다. 현행 기준에서는 '관리원'을 사용하며, 제1종 건널목의 관리원은 건널목 여건과 복잡도에 따라 배치 여부를 정한다.
Q07 [rk_ch81_17] 보안설비 고려 불필요 요소
정답 ③ 열차투시거리 및 열차 편성량
열차투시거리는 고려하지만 열차 편성량(열차 길이)은 건널목 보안설비 설치와 직접 무관.
'열차 편성량'이 함께 묶여 있어 혼동. 투시거리는 고려, 편성량은 제외.
Q08 [rk_ch7_B5_08] 보안시설 옳지 않은 것
정답 ③ 3종 건널목에는 특별한 보안시설이 필요 없다
제3종에도 최소한의 안전표지(보안시설)는 필요하다. ①②는 옳음.
'특별한 보안시설 없다' → 완전히 무시하는 것처럼 표현해 오답 유도.
Q09 [rk_ch7_B5_09] 종류별 설명 옳은 것
정답 ① 1종: 차단기와 경보기, 2종: 경보기만, 3종: 표지만
3종 분류의 정확한 설비 조합. ②③④는 순서·설비 혼동.
Q10 [rk_ch7_NEW_26] 건널목 사고예방조치 옳지 않은 것
