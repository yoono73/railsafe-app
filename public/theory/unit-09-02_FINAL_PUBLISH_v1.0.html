§0 선행 용어

변전소 (Substation)
전력계통에서 전압 변환·배분·보호를 담당하는 설비. 전철 변전소는 급전계통 전력을 전차선으로 공급한다.
직류 급전계통
직류(DC) 전력을 전차선을 통해 전동차에 공급하는 급전 방식. 도시철도·지하철 등에 주로 사용된다.
단락·과전류
사고 시 발생하는 이상 전류. 단락은 전선 사이 직접 접촉, 과전류는 정격 이상 전류 흐름. 방치하면 설비 손상.
SF6 가스 (육불화황)
절연 내력이 공기의 약 2.5배인 가스. GIS 내부 절연 매질로 사용되어 설비 소형화를 가능하게 한다.
AIS (공기절연개폐장치)
공기를 절연 매질로 사용하는 기존 방식. GIS 대비 설치 면적이 크고 외부 환경 영향을 받기 쉽다.

§1 고속도차단기 (HSCB)

개념 61 고속도차단기 (HSCB — High Speed Circuit Breaker) ⚠️ A등급
항목내용
정의 전기철도 직류 급전계통에서 단락·과전류 발생 시 수십 ms(밀리초) 이내에 회로를 차단하는 초고속 보호장치
사용 위치 전기철도 변전소 — 급전선과 전차선 사이에 설치
주 사용 방식 직류 전철에서 주로 사용 (도시철도·지하철 등)
역할 사고 전류를 수십 ms 이내에 차단 → 설비 손상 최소화, 전차선 보호
차단 속도 일반 차단기보다 훨씬 빠름 — 밀리초(ms) 단위의 초고속 동작
💡 이론 배경: 전기철도 변전소에서 사고 전류가 흐를 때 일반 차단기로는 차단이 늦어 설비 손상이 커집니다. 고속도차단기는 수십 ms 이내 차단으로 피해를 최소화합니다. 직류 전철에서 주로 사용됩니다.
⚠️ 함정 주의: "고속도차단기와 일반 차단기는 차단 속도가 같다" → 틀림
고속도차단기 = 밀리초(ms) 단위의 초고속 차단 / 일반 차단기 = 수십 ms~수백 ms 이상
▲ HSCB 초고속 차단 원리 (VIS-118)

§2 GIS (가스절연개폐장치)

개념 72 GIS — Gas Insulated Switchgear (가스절연개폐장치) A등급
항목내용
정의 SF6 가스를 절연 매질로 사용하는 고전압 개폐장치. 차단기·단로기 등 개폐 설비를 밀폐 금속 용기에 수납한 구조
절연 방식 SF6 육불화황 가스 — 절연 내력이 공기 대비 약 2.5배 높음
핵심 특징 설치 면적이 작음 (AIS 대비 1/5~1/10 수준) → 도심지 변전소 소형화에 유리
기타 특징 외부 환경 영향에 강함 / 내구성·신뢰성 높음 / 절연 내력 높음 / 밀폐 구조로 안전
비교 대상 AIS(공기절연개폐장치) — 공기 절연 방식, 설치 면적 큼, 개방형 구조
💡 이론 배경: GIS(Gas Insulated Switchgear)는 SF6 가스의 높은 절연 내력을 이용해 고압 전력기기를 소형 금속 캡슐에 밀봉합니다. 공기 절연 방식(AIS) 대비 설치 면적이 크게 줄어들어 도심지 변전소 소형화에 유리합니다.
⚠️ 함정 주의: "GIS = AIS와 같은 방식" → 틀림
GIS = SF6 가스 절연 / AIS = 공기 절연 — 설치 면적·절연 방식 모두 다름
"GIS는 면적이 넓어 대형 변전소에 쓰인다" → 틀림 (면적이 작아서 도심지에 유리)
▲ GIS 가스절연개폐장치 개념과 특징 (VIS-119)

§3 HSCB vs GIS — 역할 구분

⚡ HSCB (고속도차단기)
사고전류를 빠르게 차단하는 보호장치
수십 ms 이내 차단 / 직류 급전계통
역할: 전류 차단 (보호)
🔵 GIS (가스절연개폐장치)
SF6 가스로 고압 기기를 절연·개폐하는 설비
밀폐 구조 / 소형화 / 도심지 변전소
역할: 절연 및 개폐 (설비)
구분HSCBGIS
주기능사고전류 초고속 차단고압 전력기기 절연·개폐
핵심 키워드수십 ms / 직류 급전 / 보호SF6 가스 / 소형화 / 도심지
비교 대상일반 차단기 (느림)AIS — 공기절연 (면적 큼)
설치 위치변전소 급전선·전차선 사이변전소 내 개폐 설비

§4 시험 포인트

📌 핵심 암기 포인트
  • HSCB = 고속도차단기 = 수십 ms 이내 차단 = 직류 전철 보호장치
  • GIS = Gas Insulated Switchgear = SF6 가스 절연 = 도심지 소형화
  • HSCB는 차단 장치 / GIS는 절연·개폐 설비 — 역할 혼동 금지
  • GIS vs AIS: 면적 작음(GIS) vs 면적 큼(AIS) — 반드시 구분
함정 유형틀린 표현올바른 내용
HSCB 차단속도 "일반 차단기와 속도 같음" HSCB = 수십 ms 초고속 / 일반 차단기보다 훨씬 빠름
GIS 설치 면적 "GIS는 면적이 넓어 대형 변전소용" GIS = 면적 작음 → 도심지 소형화에 유리
GIS 절연 방식 "GIS는 공기를 절연 매질로 사용" GIS = SF6 가스 절연 / 공기 절연은 AIS
HSCB 사용 방식 "HSCB는 교류 전철에서만 사용" HSCB = 직류 전철에서 주로 사용
