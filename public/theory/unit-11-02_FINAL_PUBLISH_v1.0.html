동력집중식과 동력분산식
동력장치 위치 · 편성구조 · 급구배 성능 · 점착력 활용 · 유지보수

§0 선행 용어
동력집중식
동력장치를 기관차(또는 동력차) 1~2량에 집중하고 나머지는 부수차. 기관차 견인 방식.
동력분산식
동력장치를 여러 차량에 분산 배치. 각 차량(또는 다수 차량)에 견인전동기 장착. EMU 방식.
점착력
차륜과 레일 사이의 마찰력. 구동력 전달의 한계치. 동력분산식은 구동축이 많아 점착력 분산 활용에 유리.
부수차 (Trailer Car)
동력이 없는 차량. 동력집중식에서 기관차가 견인하는 객차·화차가 해당.
§1 핵심 비교표 (SOURCE48)
SOURCE48 · 개념48 — 기출핵심 동력집중식 vs 동력분산식 ★★★
비교 항목동력집중식동력분산식
동력장치 위치 기관차(동력차) 집중 여러 차량에 분산
편성 구조 기관차 + 객차·화차 전동차(EMU) 자력 편성
국내 예시 새마을호, KTX-1 KTX-산천, KTX-이음, 일반 전동차
급구배 성능 불리 (구동축 적음) 유리 (구동축 많아 점착력 분산 활용)
점착력 활용 기관차 집중 → 상대적 불리 우수 (전체 차축 분산)
가속 성능 상대적으로 낮음 우수 (분산 동력, 출발 부드럽)
유지보수 기관차 집중 → 간단, 용이 각 차량 분산 → 복잡, 장소 많음
객화차 융통성 객차·화차 교체 용이 편성 고정, 교체 어려움
소음 (객실) 상대적으로 적음 각 차량 전동기 → 소음 가능성
⚠ 함정: "동력집중식이 급구배에 유리하다" → ❌ 틀림. 동력분산식이 유리.
⚠ 함정: "동력집중식의 단점 — 소음이 크다" → ❌ 틀림. 소음은 동력분산식의 단점.
★ 핵심 대결: 급구배·가속 → 동력분산식 우세 / 유지보수·객화차 융통성 → 동력집중식 우세
★ 동력분산식 = EMU = 점착력 분산 활용 → 급구배·급곡선 운행에 유리

§3 시험 포인트

  • 객화차 융통성(교체 용이) = 동력집중식
