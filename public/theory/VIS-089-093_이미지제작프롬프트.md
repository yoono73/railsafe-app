## VIS-089 — AT급전 계통도

**파일명:** `VIS-089_AT급전계통도.png`  
**삽입 위치:** 4.html 개념84 BT급전 vs AT급전  

### 구성 요소 (좌→우 흐름도)
```
변전소(25kV) → 급전선(Feeder, +25kV)
                         ↓ 단권변압기(AT)
              전차선(-25kV) → 팬터그래프 → 열차
                         ↓
              레일(귀선) → 변전소
```

### 도식 설명
- 상단: 급전선(파란색 실선, +25kV 표기)
- 중단: 전차선(주황색 실선, -25kV 표기)
- AT 변압기: 급전선·전차선 사이 중간 간격마다 사각 아이콘으로 표시
- 하단: 레일 귀선(회색 점선)
- 우측 박스: 특징 요약
  - 합성전압 = 50kV
  - 전압강하 최소화
  - 고속선 표준 방식

### 이미지 생성 프롬프트 (AI용)
```
Technical diagram of AT (Auto Transformer) railway power supply system.
White background. Show: feeder wire (+25kV, blue), catenary wire (-25kV, orange),
auto transformer units spaced at intervals, rail return path (gray dashed).
Korean labels. Clean, educational infographic style. No photorealism.
```

## VIS-090 — 임피던스본드 설치위치도

**파일명:** `VIS-090_임피던스본드설치위치도.png`  
**삽입 위치:** 4.html 개념85 임피던스본드  

### 구성 요소
- 레일 2선(평행 수평선)을 좌우로 길게 배치
- 중앙에 수직 점선 = 궤도회로 경계(절연이음매)
- 경계 지점 레일 아래 사각형 아이콘 = 임피던스본드 심벌
- 좌측 구간: "A 궤도회로" (신호전류 주파수 f₁)
- 우측 구간: "B 궤도회로" (신호전류 주파수 f₂)

### 핵심 표기 (화살표)
| 방향 | 설명 |
|------|------|
| → (귀선전류) | 임피던스본드 통과 ✅ |
| ↛ (신호전류) | 인접 구간으로 차단 ❌ |

### 하단 요약 박스
```
임피던스본드 = 귀선전류 통과 ✅ + 신호전류 분리 ✅
```

### 이미지 생성 프롬프트 (AI용)
```
Technical diagram showing impedance bond installation at railway track circuit boundary.
Two parallel rails, section boundary in center with impedance bond symbol underneath.
Arrows showing: traction return current passes through (green arrow),
signal current blocked between sections (red arrow with X).
Korean labels, white background, educational diagram style.
```

## VIS-091 — 강체가선 vs 커터너리가선 단면 비교

**파일명:** `VIS-091_강체가선vs커터너리가선단면비교.png`  
**삽입 위치:** 4.html 개념86 강체가선 vs 커터너리가선  

### 2단 비교 레이아웃 (좌: 강체가선 / 우: 커터너리가선)

**강체가선(좌)**
```
[알루미늄 채널 바(Bar)]
  └─ 전차선 내장 고정
  
주 적용: 터널 내부
설비고: 낮음
탄성: 없음 ❌
최고속도: 제한적
```

**커터너리가선(우)**
```
[조가선(Messenger Wire)]
   │ │ │  ← 드로퍼(Dropper)
[전차선(Contact Wire)]

주 적용: 지상 구간
설비고: 높음
탄성: 있음 ✅
최고속도: 고속 대응
```

### 이미지 생성 프롬프트 (AI용)
```
Side-by-side cross-section comparison diagram of two railway catenary systems.
Left: Rigid catenary (bar-type, low profile, labeled "터널용").
Right: Catenary system with messenger wire, droppers, and contact wire (labeled "지상용").
Korean labels, white background, clean technical illustration.
```

## VIS-092 — 무절연AF궤도회로 구성도

**파일명:** `VIS-092_무절연AF궤도회로구성도.png`  
**삽입 위치:** 4.html 개념91 무절연AF궤도회로  

### 구성 요소 (좌→우)

```
[송신기(TX)] → f₁ 신호전류 → 레일 A구간
                                    │(차축 단락 시)
                              [수신기(RX)] → [계전기]
                              
레일 B구간 → f₂ 신호전류 (다른 주파수, 경계 없이 구분)
```

- 구간 경계: **절연이음매 없음** (점선 표시 + "無절연" 레이블)
- 두 구간 색상 구분(연파랑/연노랑)
- 열차 차축 단락 표시: 두 레일 연결 화살표 + "단락(Short) → 계전기 낙하"

### 하단 요약 박스
```
기존 방식: 절연이음매 필요 → AF궤도회로: 주파수 차이로 구간 구분
```

### 이미지 생성 프롬프트 (AI용)
```
Technical diagram of jointless (insulation-free) AF track circuit system.
Two track sections shown without insulating joints at boundary.
Left section transmitter (TX) sending f1 frequency, right section f2.
Train axle shown shorting two rails. Receiver (RX) and relay shown.
Korean labels, educational infographic, white background.
```

## VIS-093 — 1차·2차현가 위치도

**파일명:** `VIS-093_1차2차현가위치도.png`  
**삽입 위치:** 4.html 개념93 1차현가·2차현가 및 개념94 대차 기본구조  

### 차량 단면 측면도 구성

```
┌────────────────────────┐
│        차  체          │ ← 차체(Car Body)
└───────────┬────────────┘
            │ ← 2차현가 (공기스프링)
        [대차 프레임]     ← Bogie Frame
            │ ← 1차현가 (코일스프링)
      ══ 차  축 ══        ← Axle (차륜·레일 접촉)
        ────────          ← 레일
```

### 각 부위 설명 박스
| 현가 | 위치 | 역할 |
|------|------|------|
| 1차현가 | 차축 ↔ 대차프레임 | 고주파 진동·사행동 흡수 |
| 2차현가 | 대차프레임 ↔ 차체 | 저주파 진동·승차감 향상 |

### 이미지 생성 프롬프트 (AI용)
```
Technical cross-section diagram of railway bogie (truck) suspension system.
Show car body at top, bogie frame in middle, axle/wheels at bottom on rail.
Label: primary suspension (1차현가) between axle and bogie frame (coil spring symbol),
secondary suspension (2차현가) between bogie frame and car body (air spring symbol).
Korean labels, white background, clean educational diagram.
```
