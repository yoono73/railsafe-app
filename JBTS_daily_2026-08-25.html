Q2. 정보통신설비의 유지보수(보전) 방식 3가지를 쓰고, 각각의 개념·시행 시점·장단점을 비교 설명하시오.

방식개념 / 시점장점단점
① 예방보전(PM, Preventive Maintenance) 고장 발생 전 정해진 주기로 정기점검·부품교체 돌발 고장 감소, 설비 수명 연장, 계획적 운용 정상 부품도 교체 → 비용·공수 과다
② 사후보전(CM, Corrective Maintenance) 고장 발생 후 수리·교체 불필요한 점검 비용 없음, 단순 서비스 중단(다운타임) 발생, MTTR 증가
③ 예측보전(PdM, Predictive Maintenance) 온도·전류·트래픽 등 상태 모니터링으로 열화 추세를 분석해 고장 직전 조치 비용 최소화 + 가동률 최대화, NMS·AI 연계 가능 센서·분석 시스템 등 초기 투자 필요
🔑 "전-후-직전"으로 구분: 예방=고장 前 정기 / 사후=고장 後 수리 / 예측=상태감시 후 고장 直前.
연결 포인트 — 예방·예측보전은 MTBF↑, 신속한 사후보전 체계는 MTTR↓ → 결국 가용성 A = MTBF/(MTBF+MTTR) 향상(C06). 개량보전(CM, Corrective→설비 자체 개선)·보전예방(MP)까지 5가지로 확장 출제되는 경우도 있음.

Q4. ICMP(Internet Control Message Protocol)에 대해 답하시오.
(1) 정의와 동작 계층을 쓰시오.
(2) 대표적인 메시지 유형 4가지와 각각의 용도를 쓰시오.
(3) ICMP를 이용한 대표 진단 명령 2가지와 그 원리를 설명하시오.
모범답안 보기

(1) 정의 — IP 통신 과정에서 발생한 오류를 송신측에 보고하고 네트워크 상태 정보를 전달하기 위한 제어·오류보고 프로토콜. 네트워크(IP) 계층에서 동작하며 IP 패킷의 데이터부에 캡슐화되어 전송된다. (신뢰성·흐름제어 기능은 없음)

메시지용도
① Echo Request / Echo Reply상대 호스트의 도달 가능 여부 확인 (ping의 기반)
② Destination Unreachable목적지 호스트·네트워크·포트에 도달 불가함을 통보
③ Time ExceededTTL이 0이 되어 패킷이 폐기되었음을 통보 (라우팅 루프 검출)
④ Redirect더 좋은 경로의 라우터가 있음을 호스트에 알려 경로 변경 유도
(⑤ Source Quench)혼잡 발생 시 송신 속도를 낮추도록 요청 (현재는 거의 미사용)

(3) 진단 명령
• ping — Echo Request를 보내고 Echo Reply 수신 여부·왕복지연(RTT)·손실률로 연결성과 응답시간을 확인.
• traceroute(tracert) — TTL을 1부터 1씩 증가시켜 보내면 각 라우터가 Time Exceeded를 회신 → 회신 주소를 순서대로 모아 경유 경로와 구간별 지연을 파악.

🔑 "IP 계층, 오류보고 전용"이 핵심. Echo=ping / Time Exceeded=traceroute 로 메시지↔명령 짝을 붙여서 암기.
비교 포인트 — SNMP는 응용계층·UDP·관리정보(MIB) 수집, ICMP는 네트워크계층·오류보고. "장애를 발견하는 건 SNMP Trap, 장애 지점을 추적하는 건 ICMP"로 연결 정리(T03↔T05).
