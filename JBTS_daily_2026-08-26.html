Q1. 감리원 업무에 관하여 답하시오.
(1) 감리원 업무범위 중 「자재」와 「안전」에 해당하는 항목을 각각 1가지씩 쓰시오. (2점)
(2) 빈칸 — 감리원은 공사가  대로 시공되는지를 확인하고, 공사 완료 시  의 검토 및  확인을 수행한다. (3점)
답안 작성란
모범답안 확인

(1)

  • 자재 — 사용자재의 규격 검토 및 검사
  • 안전 — 재해예방 및 안전관리

(2) ① 설계도서 ② 준공도서 ③ 준공

참고 — 감리원 업무범위 10가지 전체: ①공사계획·공정표 검토 ②시공상세도면 검토 ③설계도서의 현장적합성 확인 ④설계도서 준수 여부 확인 ⑤시공 진척상태 조사 ⑥사용자재 규격검토·검사 ⑦재해예방·안전관리 ⑧설계변경 검토 ⑨하도급 타당성 검토 ⑩준공도서 검토·준공확인

암기 포인트 — “계획·도면 → 자재 → 시공 → 안전 → 변경·하도급 → 준공” 공사 흐름 순서. 항목을 지정해 묻는 유형(자재/안전/설계변경 등)이 나오면 그 키워드가 들어간 항목만 정확히 골라 쓴다. 답안은 반드시 명사형 어구로 끊어 쓸 것.
C03 공사원가 계산역산형(계산) · 5점
Q2. 어느 정보통신공사의 원가가 다음과 같다. 재료비와 총원가를 각각 구하시오. (계산과정 포함)
노무비50,000,000원경비20,000,000원
일반관리비율6%이윤율15%
일반관리비9,000,000원
답안 작성란
모범답안 확인
① 일반관리비 = 순공사원가 × 6% → 순공사원가 = 9,000,000 ÷ 0.06 = 150,000,000원 ② 순공사원가 = 재료비 + 노무비 + 경비 150,000,000 = 재료비 + 50,000,000 + 20,000,000 ∴ 재료비 = 80,000,000원 ③ 이윤 = (노무비 + 경비 + 일반관리비) × 15% = (50,000,000 + 20,000,000 + 9,000,000) × 0.15 = 79,000,000 × 0.15 = 11,850,000원 ④ 총원가 = 순공사원가 + 일반관리비 + 이윤 = 150,000,000 + 9,000,000 + 11,850,000 ∴ 총원가 = 170,850,000원
구분답
재료비80,000,000원
총원가170,850,000원
암기 포인트 — 이윤 산정 기준에 재료비는 포함되지 않는다(노무비+경비+일반관리비만). 이 함정이 역산형에서 가장 많이 틀리는 지점. 순서는 언제나 순공사원가 → 일반관리비(6%) → 이윤(15%) → 총원가.

C06 가용성 / RAS서술형 + 비교계산 · 5점
Q4. RAS에 관하여 답하시오.
(1) RAS의 3요소를 쓰고 각각의 대표 지표를 함께 쓰시오. (3점)
(2) 아래 두 시스템의 가용성을 각각 구하고 어느 쪽이 우수한지 판단하시오. (2점)
구분시스템 甲시스템 乙
MTBF900 시간2,400 시간
MTTR3 시간12 시간
답안 작성란
모범답안 확인

(1) RAS 3요소

요소의미대표 지표
Reliability (신뢰성)고장 없이 오래 동작하는 성질MTBF (평균고장간격)
Availability (가용성)필요할 때 사용 가능한 비율A = MTBF / (MTBF+MTTR) × 100%
Serviceability (보수성)고장 시 빠르게 복구하는 성질MTTR (평균수리시간)

(2) 가용성 계산

甲 : A = 900 / (900 + 3) × 100 = 900 / 903 × 100 ≒ 99.67 % 乙 : A = 2,400 / (2,400 + 12) × 100 = 2,400 / 2,412 × 100 ≒ 99.50 % ∴ 甲(99.67%) > 乙(99.50%) → 가용성은 甲이 우수

판단 — 乙이 신뢰성(MTBF)은 더 높지만, 보수성(MTTR)이 나빠 가용성은 甲이 앞선다. 가용성은 MTBF 단독이 아니라 MTBF와 MTTR의 비로 결정된다.

암기 포인트 — MTBF = 총 정상동작시간 ÷ 고장횟수, MTTR = 총 수리시간 ÷ 고장횟수. “MTBF 큰 쪽이 무조건 가용성 우수”가 아니라는 함정이 자주 출제된다. 답안에는 수식 → 대입 → 백분율(소수 둘째자리) 순서로 반드시 계산과정을 남길 것.
