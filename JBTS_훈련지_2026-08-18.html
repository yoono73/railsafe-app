C03공사원가 · 계산형
재료비 3,000만원, 노무비 2,000만원, 경비 1,000만원인 공사가 있다. 일반관리비율 6%, 이윤율 15%일 때 순공사원가·일반관리비·이윤·총원가를 각각 구하시오.
풀이
  1. 순공사원가 = 재료비+노무비+경비 = 3,000+2,000+1,000 = 6,000만원
  2. 일반관리비 = 순공사원가 × 6% = 6,000 × 0.06 = 360만원
  3. 이윤 = (노무비+경비+일반관리비) × 15% = (2,000+1,000+360) × 0.15 = 3,360 × 0.15 = 504만원
  4. 총원가 = 6,000+360+504 = 6,864만원
함정 이윤 산정 기초에 재료비는 포함되지 않는다. (노무비+경비+일반관리비만)

T03SNMP · 서술+열거형
SNMP의 메시지(PDU) 5가지를 쓰고, 각각의 기능과 사용 포트를 설명하시오. 또한 SNMP가 사용하는 전송계층 프로토콜과, 에이전트가 관리자에게 능동적으로 보내는 메시지는 무엇인가?
메시지기능포트
GetRequest관리자→에이전트, 특정 MIB 객체 값 요청161
GetNextRequest다음 MIB 객체 값 요청(테이블 순회)161
SetRequestMIB 객체 값 설정·변경161
GetResponse에이전트→관리자, 요청에 대한 응답161
Trap에이전트→관리자, 이벤트 발생 시 능동 통보162
  • 전송계층: UDP (비연결형, 오버헤드 최소) / 계층: 애플리케이션 계층
  • 에이전트가 요청 없이 먼저 보내는 단방향 메시지 = Trap (162번 포트)
  • 연결 토픽 T01 NMS 4요소: 관리스테이션 + 에이전트 + MIB + SNMP
