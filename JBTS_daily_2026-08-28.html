Q1. 아래는 어느 정보통신설비 구축 현장에서 적용한 8가지 조치이다. 각 조치를 「신뢰성 · 안전성 · 관리성 · 경제성」 4대 요소 중 하나로 분류하고, 4대 요소 각각의 정의를 한 줄로 쓰시오. (8점)
번호현장 조치해당 요소
①주요 통신장비를 이중화(Active-Standby)로 구성
②통신실 접지저항을 10Ω 이하로 시공하고 SPD(피뢰기) 설치
③NMS를 도입해 원격에서 장애를 감시·통보하도록 구성
④표준시장단가를 적용하고 LCC(생애주기비용) 분석으로 자재 선정
⑤장비 랙에 내진 브래킷을 설치
⑥MTBF가 긴 등급의 부품으로 교체
⑦모듈형 카드 구조를 채택해 MTTR을 단축
⑧동일 규격 케이블을 일괄 구매하여 단가를 절감
✍ 여기에 답안을 작성하세요
모범답안 보기 [분류]
요소해당 번호정의(한 줄)
신뢰성
(Reliability)		①, ⑥ 시스템이 고장 없이 규정된 기능을 지속 수행하는 성질. 척도 = MTBF, 수단 = 이중화·고신뢰 부품
안전성
(Safety)		②, ⑤ 인명·설비를 전기적·물리적 위해로부터 보호하는 성질. 수단 = 접지·피뢰(SPD)·내진·방화
관리성
(Maintainability)		③, ⑦ 고장 발생 시 신속히 발견·복구하고 운용을 쉽게 하는 성질. 척도 = MTTR, 수단 = 모듈화·원격감시(NMS)
경제성
(Economy)		④, ⑧ 초기투자비와 운용비를 합한 LCC를 최소화하는 성질. 수단 = 표준시장단가·표준화·일괄구매
🔑 암기 포인트 — 「신·안·관·경」
신뢰성 = MTBF·이중화 / 안전성 = 접지·피뢰·내진 / 관리성 = MTTR·모듈화·원격 / 경제성 = LCC·표준시장단가
헷갈림 주의: 이중화는 신뢰성(고장을 안 나게), 모듈화는 관리성(고장 나면 빨리 고치게). ⑥은 MTBF → 신뢰성, ⑦은 MTTR → 관리성으로 척도로 구분하면 틀리지 않습니다.

(3) NMS의 구성 4요소를 쓰시오.

T02계산형
Q3. 오류제어 방식인 ARQ에 관하여 아래에 답하시오. (7점)
[조건] 프레임 전송시간 Tf = 1 ms, 편도 전파지연 Tp = 2 ms 송신측 윈도우 크기 N = 7, 프레임은 0번부터 순차 전송 6번 프레임까지 전송한 시점에 3번 프레임의 오류가 확인됨
(1) Stop-and-Wait ARQ의 전송효율(채널 이용률)을 구하시오. (2점)
(2) Go-Back-N ARQ 적용 시 재전송되는 프레임 번호와 개수를 쓰시오. (2점)
(3) Selective Repeat ARQ 적용 시 재전송되는 프레임 번호와 개수를 쓰시오. (1점)
(4) (2)·(3)의 결과를 근거로 두 방식의 장단점을 각각 1줄로 쓰시오. (2점)
✍ 여기에 답안을 작성하세요
모범답안 보기 (1) Stop-and-Wait 전송효율
U = Tf / (Tf + 2Tp) = 1 / (1 + 2×2) = 1 / 5 = 0.2 → 20 %
※ 1프레임 보내고 ACK를 기다리므로 왕복지연 2Tp가 그대로 낭비된다. (참고: a = Tp/Tf = 2 로 두면 U = 1/(1+2a) 로도 계산 가능) (2) Go-Back-N
오류난 3번 이후 전부 재전송 → 3, 4, 5, 6번 → 4개 (3) Selective Repeat
오류난 3번만 재전송 → 1개 (4) 장단점
방식장점단점
Go-Back-N수신측 버퍼 불필요, 구조 단순정상 프레임(4·5·6)까지 재전송 → 대역 낭비
Selective Repeat오류 프레임만 재전송 → 전송효율 최고수신측 버퍼·재정렬 필요 → 구현 복잡
🔑 암기 포인트
· Stop-and-Wait 효율 U = Tf/(Tf+2Tp) = 1/(1+2a) — 2Tp(왕복)인 것 놓치지 말 것
· 슬라이딩윈도우 효율 U = N/(1+2a) (단, N < 1+2a 일 때. N ≥ 1+2a 이면 U=1)
· 재전송 개수: GBN = 오류번호부터 마지막까지, SR = 오류난 것 1개
· 윈도우 크기 상한: GBN = 2ⁿ−1, SR = 2ⁿ⁻¹ (n = 순서번호 비트수)
T04수치 계산형
Q4. OTDR로 광케이블 선로를 측정하였다. 아래에 답하시오. (7점)
[조건] 광섬유 코어 굴절률 n = 1.46, 진공중 광속 c = 3 × 10⁸ m/s ① 단선 의심 지점에서 반사된 펄스의 왕복 소요시간 t = 10 μs ② 기점에서 1.0 km 지점과 2.0 km 지점의 후방산란 레벨차 = 0.35 dB ③ 1.5 km 지점에서 계단형 레벨 하강 0.10 dB 관측
(1) 단선(반사) 지점까지의 거리를 구하시오. (3점)
(2) 이 광섬유의 손실계수(dB/km)를 구하시오. (2점)
(3) 1.5 km 지점의 계단형 하강은 무엇을 의미하는가? (1점)
(4) OTDR 파형에서 프레넬 반사가 나타나는 지점 2곳을 쓰시오. (1점)
✍ 여기에 답안을 작성하세요
모범답안 보기 (1) 거리
광섬유 내 광속 v = c / n = (3×10⁸) / 1.46 = 2.0548×10⁸ m/s 거리 L = (v × t) / 2 ← 왕복이므로 2로 나눔 = (2.0548×10⁸ × 10×10⁻⁶) / 2 = 2054.8 / 2 = 1027.4 m ≒ 1.03 km
※ 통합식: L = c·t / (2n) = (3×10⁸ × 10⁻⁵)/(2×1.46) = 3000/2.92 = 1027.4 m (2) 손실계수
α = 레벨차 / 거리차 = 0.35 dB / (2.0 − 1.0) km = 0.35 dB/km
(3) 반사 스파이크 없이 레벨만 계단형으로 떨어진 것 → 융착접속(Splice) 손실 (접속손실 0.10 dB). 커넥터라면 프레넬 반사 스파이크를 동반한다. (4) 프레넬 반사 발생 지점 → ① 커넥터·기계식 접속점 ② 광섬유 끝단(단선·종단면)
🔑 암기 포인트
· 거리공식 L = c·t / (2n) — 2로 나누는 것(왕복)과 n으로 나누는 것 둘 다 필수
· OTDR 파형 판독 3종
  — 완만한 우하향 경사 = 후방산란(레일리 산란) → 광섬유 고유손실
  — 뾰족한 스파이크 = 프레넬 반사 → 커넥터·끝단
  — 계단형 급락(스파이크 없음) = 융착접속 손실 또는 과도 굽힘
· OTDR 측정항목: 거리 · 손실 · 접속점 위치 · 단선 위치 · 반사감쇠량(ORL)
· 데드존: 반사 직후 측정 불가 구간 — 기점에 더미(펄스억제) 코드를 넣어 회피
